---
title: System architecture
description: Follow an inference request through policy, funding, routing, and settlement.
---

Zorveus separates management operations from model traffic. The management surface owns organizations, apps, connections, credentials, caps, and product users. The OpenAI-compatible inference gateway handles model requests.

For a wallet-funded request, the gateway:

1. Authenticates the inference key and resolves its connection.
2. Resolves product-user attribution when supplied or required.
3. Checks model policy, caps, credit mode, and available funding.
4. Reserves an estimated amount before upstream work begins.
5. Selects an eligible provider route and proxies the request.
6. Settles recorded usage and releases unused reserved funds.

For BYOK, provider routing uses an eligible organization credential. The upstream provider bills the credential owner, while Zorveus records usage and any configured platform fee.

Streaming changes response delivery, not the policy and accounting lifecycle. A disconnect or interrupted settlement can require asynchronous release or reconciliation.
