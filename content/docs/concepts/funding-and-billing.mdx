title: Funding and billing
description: Understand wallet-funded inference, BYOK routing, and product-user credit enforcement.

## Wallet-funded inference

Zorvues supports inference requests that are funded by an organization wallet. The organization wallet is a balance of funds that can be used to pay for inference requests. The wallet can be funded by a variety of methods, including credit card, ACH, and wire transfer.

When an inference request is made, the Zorveus API checks the organization wallet balance to determine if there are sufficient funds to cover the cost of the request. If there are sufficient funds, the request is processed and the cost is deducted from the wallet balance. If there are insufficient funds, the request is rejected.

## Bring your own key

With BYOK, Zorveus routes through an eligible organization-owned provider credential. The upstream provider bills that account directly. Usage records still include an estimated `provider_cost`; `sell_cost` can include a configured BYOK platform fee, so it is not universally zero. Currently we allow up to `$25k` free monthly usage for BYOK inference.

## Product-user credits

Credit grants allocate a consumable balance to a product user. Whether that balance blocks a request depends on the app connection’s `credit_mode`. Credits do not replace the underlying organization funding route. Here, the inference request must include an identifiable product user (`external_user_id` or `product_user_id`).

All billing amounts returned by the API are decimal strings. Use a decimal library for calculations and the wallet ledger for authoritative reconciliation.
