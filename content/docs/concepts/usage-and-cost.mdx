# Usage and Cost Accounting

Every inference request that traverses the Zorveus Gateway generates an immutable **Usage Event** in your organization ledger.

---

## Usage Event Dimensions

Each usage record captures full contextual metadata:

| Dimension | Description |
| :--- | :--- |
| **`timestamp`** | Timezone-aware ISO 8601 timestamp (`2026-08-13T20:45:00Z`). |
| **`app_id`** | Application identity associated with the connection. |
| **`model`** | Canonical model name resolved (e.g. `openai/gpt-4.1-mini`). |
| **`provider`** | Underlying provider executing inference (`openai`, `anthropic`, `gemini`, etc.). |
| **`billing_mode`** | `wallet_funded` or `byok`. |
| **`prompt_tokens`** | Input tokens parsed from client request. |
| **`completion_tokens`** | Output tokens generated by the model. |
| **`total_tokens`** | Sum of prompt and completion tokens. |
| **`provider_cost`** | Estimated raw wholesale provider cost based on published rates. |
| **`sell_cost`** | Actual retail amount charged to the Zorveus organization wallet. |
| **`product_user_id`** | Attribution to your startup's customer (if supplied). |
| **`member_id`** | Attribution to the dashboard team member (for internal tools). |

---

## Querying and Filtering Usage

Usage data is accessible via the [Dashboard API](/api-reference) with flexible multi-dimensional filtering:
- Group by day, week, or month.
- Filter simultaneously by `app_id`, `model`, `product_user_id`, and `billing_mode`.
- Export raw event streams or aggregate summary totals for custom reporting.
