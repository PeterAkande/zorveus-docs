# Testing Draft Apps

While an OAuth app is in `draft` status, only organization members and explicitly invited **Test Users** can complete the consent flow.

---

## Adding Test Users

1. In [app.zorveus.com](https://app.zorveus.com), navigate to your app settings.
2. Under **Test Users**, enter developer and QA email addresses.
3. Test users can authorize the application without public verification badges.
