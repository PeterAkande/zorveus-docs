Redirect the user's browser to the Zorveus authorization screen to request model access permissions under their own funding account.

<ApiEndpoint method="GET" path="/oauth/authorize" />

<KeyInserter type="client" label="Client ID" placeholder="zrv_client_your_client_id" />

## Query parameters

<ParamField name="response_type" type="string" required>
  Must be `code`.
</ParamField>

<ParamField name="client_id" type="string" required>
  Your app's registered Client ID (`zrv_client_...`).
</ParamField>

<ParamField name="redirect_uri" type="string" required>
  The exact callback URL registered in your app settings in the dashboard.
</ParamField>

<ParamField name="scope" type="string" required>
  Space-separated permission scopes. Must include `inference:write` and at least one model scope (e.g. `models:*` or `models:openai/*`).
</ParamField>

<ParamField name="code_challenge" type="string" required>
  The Base64URL-encoded SHA-256 hash of your cryptographic code verifier.
</ParamField>

<ParamField name="code_challenge_method" type="string" required>
  Must be `S256`.
</ParamField>

<ParamField name="state" type="string" required>
  A cryptographically secure random string used to prevent CSRF attacks. Verify this string matches upon callback.
</ParamField>

## Code example: Generating the authorization URL

Use the SDK helper to generate your PKCE challenge and construct the authorization URL:

<CodeGroup titles={["TypeScript", "Python"]}>

```typescript
import { ZorveusOAuth } from "@zorveus/sdk";

// 1. Generate high-entropy PKCE verifier and S256 challenge
const { codeVerifier, codeChallenge } = await ZorveusOAuth.generatePKCE();

// Store codeVerifier in a secure, HTTP-only session cookie for the callback
session.codeVerifier = codeVerifier;
session.state = crypto.randomUUID();

// 2. Construct authorization URL
const authUrl = ZorveusOAuth.getAuthorizationUrl({
  clientId: "zrv_client_your_client_id",
  redirectUri: "https://myapp.com/api/auth/callback",
  scope: "inference:write models:*",
  codeChallenge,
  state: session.state,
});

// 3. Redirect the user's browser
res.redirect(authUrl);
```

```python
import secrets
from zorveus import ZorveusOAuth

# 1. Generate PKCE verifier and challenge
pkce = ZorveusOAuth.generate_pkce()

# Store verifier in server-side session
session["code_verifier"] = pkce.code_verifier
session["state"] = secrets.token_urlsafe(32)

# 2. Build redirect URL
auth_url = ZorveusOAuth.get_authorization_url(
    client_id="zrv_client_your_client_id",
    redirect_uri="https://myapp.com/api/auth/callback",
    scope="inference:write models:*",
    code_challenge=pkce.code_challenge,
    state=session["state"],
)

# 3. Redirect user
return redirect(auth_url)
```

## Redirect callback

When the user grants consent, Zorveus redirects their browser back to your `redirect_uri` with a temporary code:

```text
https://myapp.com/api/auth/callback?code=zorveus_code_abc123xyz&state=YOUR_RANDOM_STATE
```

1. Verify that `state` matches the value you originally stored in your session.
2. Exchange the single-use `code` and your saved `code_verifier` for an access token using [Token exchange](/oauth/token-exchange).
