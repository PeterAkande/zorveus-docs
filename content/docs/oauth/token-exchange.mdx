---
title: Token exchange
description: Exchange short-lived authorization codes and PKCE verifiers for scoped inference tokens.
---

<ApiEndpoint method="POST" path="/oauth/token" />

Once the user approves your app, Zorveus redirects to your `redirect_uri` with `?code=...&state=...`. A confidential client's backend makes a server-to-server POST request to exchange the code for an inference token

---

## Token request parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| **`grant_type`** | string | Yes | Must be `authorization_code`. |
| **`client_id`** | string | Yes | Your application Client ID. |
| **`client_secret`** | string | Yes, For confidential clients | Your confidential client secret. Public clients omit it. |
| **`code`** | string | Yes | Single-use authorization code from redirect callback. |
| **`code_verifier`** | string | Yes | Plaintext string used to generate `code_challenge`. |
| **`redirect_uri`** | string | Yes | Exact URI sent in initial authorization request. |

---

## Code example

<CodeGroup titles={["Node.js (TypeScript)", "Python", "cURL"]}>

```typescript
const response = await fetch("https://api.zorveus.com/oauth/token", {
  method: "POST",
  headers: { "Content-Type": "application/x-www-form-urlencoded" },
  body: new URLSearchParams({
    grant_type: "authorization_code",
    client_id: "zrv_client_your_client_id",
    client_secret: "zrv_client_secret_your_client_secret",
    code: authCodeFromRedirect,
    code_verifier: codeVerifier,
    redirect_uri: "https://myapp.com/callback",
  }),
});

const tokenData = await response.json();
if (!response.ok) throw new Error(tokenData.error?.code ?? "Token exchange failed");
const accessToken = tokenData.access_token;
```

```python
import requests

response = requests.post(
    "https://api.zorveus.com/oauth/token",
    headers={"Content-Type": "application/x-www-form-urlencoded"},
    data={
        "grant_type": "authorization_code",
        "client_id": "zrv_client_your_client_id",
        "client_secret": "zrv_client_secret_your_client_secret",
        "code": auth_code_from_redirect,
        "code_verifier": code_verifier,
        "redirect_uri": "https://myapp.com/callback",
    },
)

response.raise_for_status()
token_data = response.json()
access_token = token_data["access_token"]
```

```bash
curl -X POST https://api.zorveus.com/oauth/token \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "grant_type=authorization_code" \
  -d "client_id=zrv_client_your_client_id" \
  -d "client_secret=zrv_client_secret_your_client_secret" \
  -d "code=auth_code_from_redirect" \
  -d "code_verifier=original_plain_code_verifier" \
  -d "redirect_uri=https://myapp.com/callback"
```

## Token response

HTTP `200` returns `access_token`, `token_type`, `scope`, `expires_in`, `app_connection_id`, and `api_base`. `expires_in` can be null. When it is a number, honor that lifetime. The token can also become invalid through revocation or reauthorization

`api_base` is the inference base URL. Store the token against the user who initiated authorization. Do not log it. Public clients omit `client_secret`. Neither client type receives a refresh token

See [OAuth errors](/oauth/errors) for the structured error object and [Use the token](/oauth/use-the-token) for inference
