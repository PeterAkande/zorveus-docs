---
title: Token exchange
description: Exchange authorization codes and PKCE verifiers for scoped inference tokens.
---

Once the user approves your app, Zorveus redirects to your `redirect_uri` with a temporary `code`. Your backend exchanges this code and your PKCE `code_verifier` for a scoped access token.

<ApiEndpoint method="POST" path="/oauth/token" />

<KeyInserter type="client" label="Client ID" placeholder="zrv_client_your_client_id" />

## Code examples

<CodeGroup titles={["TypeScript", "Python", "cURL"]}>

```typescript
import { ZorveusOAuth } from "@zorveus/sdk";

// Retrieve codeVerifier and state from your user's session
const { code, state } = req.query;
if (state !== session.state) {
  throw new Error("CSRF state mismatch");
}

const tokenData = await ZorveusOAuth.exchangeCode({
  clientId: "zrv_client_your_client_id",
  clientSecret: process.env.ZORVEUS_CLIENT_SECRET, // Omit for public clients
  code: String(code),
  codeVerifier: session.codeVerifier,
  redirectUri: "https://myapp.com/api/auth/callback",
});

// Save token securely against the user account
await db.users.update({
  where: { id: currentUserId },
  data: { zorveusAccessToken: tokenData.access_token },
});
```

```python
from zorveus import ZorveusOAuth

# Verify state from session
if request.args.get("state") != session.get("state"):
    raise ValueError("CSRF state mismatch")

token_data = ZorveusOAuth.exchange_code(
    client_id="zrv_client_your_client_id",
    client_secret=os.environ.get("ZORVEUS_CLIENT_SECRET"),  # Omit for public clients
    code=request.args["code"],
    code_verifier=session["code_verifier"],
    redirect_uri="https://myapp.com/api/auth/callback",
)

# Save token in database
db.save_user_token(user_id=current_user_id, access_token=token_data.access_token)
```

```bash
curl -X POST https://api.zorveus.com/oauth/token \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "grant_type=authorization_code" \
  -d "client_id=zrv_client_your_client_id" \
  -d "client_secret=zrv_client_secret_your_secret" \
  -d "code=zorveus_code_abc123xyz" \
  -d "code_verifier=original_plain_code_verifier" \
  -d "redirect_uri=https://myapp.com/api/auth/callback"
```

## Request parameters

<ParamField name="grant_type" type="string" required>
  Must be `authorization_code`.
</ParamField>

<ParamField name="client_id" type="string" required>
  Your app's Client ID.
</ParamField>

<ParamField name="code" type="string" required>
  The single-use authorization code received from the callback redirect.
</ParamField>

<ParamField name="code_verifier" type="string" required>
  The original plaintext PKCE verifier generated before the authorization request.
</ParamField>

<ParamField name="redirect_uri" type="string" required>
  The exact redirect URI used in the authorization request.
</ParamField>

<ParamField name="client_secret" type="string">
  Required for confidential backend apps. Public apps (mobile, single-page apps) omit this.
</ParamField>

## Response format

```json
{
  "access_token": "zrv_usr_9a8b7c6d5e4f3a2b1c0d",
  "token_type": "Bearer",
  "scope": "inference:write models:*",
  "expires_in": 2592000,
  "app_connection_id": "appcon_abc123",
  "api_base": "https://api.zorveus.com/v1"
}
```

<ResponseField name="access_token" type="string" required>
  The scoped inference bearer token to use for model requests on behalf of this user.
</ResponseField>

<ResponseField name="token_type" type="string" required>
  Always `Bearer`.
</ResponseField>

<ResponseField name="scope" type="string" required>
  The granted scopes approved by the user.
</ResponseField>

<ResponseField name="api_base" type="string" required>
  The base gateway endpoint for inference calls (typically `https://api.zorveus.com/v1`).
</ResponseField>

## Making requests with the token

Pass the returned `access_token` in the `Authorization` header on standard OpenAI or native SDK completions. Costs are billed directly to the authorizing user's Zorveus funding account:

```typescript
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: tokenData.api_base,
  apiKey: tokenData.access_token,
});

const response = await client.chat.completions.create({
  model: "openai/gpt-4.1-mini",
  messages: [{ role: "user", content: "Hello from my OAuth app!" }],
});
```
