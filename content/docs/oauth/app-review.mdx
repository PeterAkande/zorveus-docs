---
title: App review and publishing
description: Prepare an OAuth app for users outside its test audience.
---

Configure your app's identity, redirect URIs, scopes, models, test users, and consent spending policy in the [dashboard](https://app.zorveus.com). Test the authorization, inference, and disconnect flows before submitting it for review

| Status | Meaning |
| --- | --- |
| `draft` | Editable and available to permitted testers |
| `submitted_for_review` | Waiting for review |
| `active` | Available outside the test audience |
| `rejected` | Returned with review feedback |
| `suspended` | Authorization is blocked |
| `deleted` | No longer active |

Manage submission and cancellation in the dashboard. Treat an app as publicly available only when its status is `active`. See [Testing draft apps](/oauth/testing-draft-apps)
