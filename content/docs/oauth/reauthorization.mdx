# Reauthorization Semantics

When an existing user re-authorizes your application:
- **One Logical Active Connection**: Zorveus maintains exactly one active `user_oauth` connection per app-user pairing.
- **Token Invalidation**: Reauthorization revokes all previous inference tokens issued for that connection and mints one replacement token.
- **Policy Updates**: Any modified spending caps, selected funding organizations, or model permissions take effect immediately upon completion.
