Use Zorveus to send model requests, attribute usage to your customers, and enforce AI spending policies. Configure your app in the dashboard, then call Zorveus from your code

## Use the client you already have

OpenAI-compatible clients use `https://api.zorveus.com/v1`. Native Anthropic clients use `https://api.zorveus.com`. Zorveus also provides Python and TypeScript SDKs, OpenAI adapters, a Vercel AI SDK adapter, and React OAuth components

| Client | Install | Guide |
| --- | --- | --- |
| OpenAI Python or TypeScript | `pip install openai` or `npm install openai` | [Business quickstart](/getting-started/startup-quickstart) |
| Zorveus Python | `pip install zorveus` | [Product users](/startups/product-users) |
| Zorveus TypeScript | `npm install @zorveus/sdk` | [Product-user quickstart](/getting-started/product-user-quickstart) |
| OpenAI adapters | `pip install 'zorveus[openai]'` or `npm install @zorveus/sdk openai` | [Inference](/inference/overview) |
| Vercel AI SDK adapter | `npm install @zorveus/sdk ai @ai-sdk/openai` | [Streaming](/inference/streaming) |
| React OAuth components | `npm install @zorveus/react @zorveus/sdk` | [OAuth quickstart](/getting-started/oauth-app-quickstart) |

Choose a model from [the catalog](https://www.zorveus.com/models), then verify it with `GET /v1/models` using your inference key. Model access and task capabilities vary by route
