## Make your first API request

Call models from OpenAI, Google Gemini, Anthropic, Jev, and more using the standard OpenAI SDK or cURL. Set your base URL to `https://api.zorveus.com/v1` and use your Zorveus API key (`zrv_...`).

<CodeGroup titles={["Python", "TypeScript", "cURL"]}>

```python
from openai import OpenAI

client = OpenAI(
    api_key="zrv_your_api_key",
    base_url="https://api.zorveus.com/v1",
)

response = client.chat.completions.create(
    model="openai/gpt-4.1-mini",
    messages=[{"role": "user", "content": "Say hello in five words."}],
)

print(response.choices[0].message.content)
```

```typescript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "zrv_your_api_key",
  baseURL: "https://api.zorveus.com/v1",
});

const response = await client.chat.completions.create({
  model: "openai/gpt-4.1-mini",
  messages: [{ role: "user", content: "Say hello in five words." }],
});

console.log(response.choices[0].message.content);
```

```bash
curl https://api.zorveus.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer zrv_your_api_key" \
  -d '{
    "model": "openai/gpt-4.1-mini",
    "messages": [{"role": "user", "content": "Say hello in five words."}]
  }'
```

</CodeGroup>

A successful request returns HTTP `200` with the model's response. Follow [Make your first API request](/getting-started/startup-quickstart) to get an API key and run your first call, or browse the [available models](/api-reference/models).
