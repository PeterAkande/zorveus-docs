## Quickstart

You can use the official **Zorveus SDKs** (`@zorveus/sdk` for TypeScript, `zorveus` for Python), framework adapters (`@zorveus/sdk/openai`, `@zorveus/sdk/vercel`, `zorveus[openai]`), or point any OpenAI-compatible client to `https://api.zorveus.com/v1`.

<CodeGroup titles={["TypeScript (@zorveus/sdk)", "Python (zorveus)", "Python (ZorveusOpenAI)", "TypeScript (Vercel AI SDK)", "cURL", "TypeScript (OpenAI SDK)", "Go", "Rust"]}>

```typescript
import { Zorveus } from "@zorveus/sdk";

const client = new Zorveus({
  apiKey: "zrv_your_api_key",
});

async function main() {
  const completion = await client.chat.completions.create({
    model: "openai/gpt-4.1-mini",
    messages: [
      { role: "user", content: "Explain quantum computing in one sentence." },
    ],
  });

  console.log(completion.choices[0].message.content);
}

main();
```

```python
from zorveus import Zorveus

client = Zorveus(api_key="zrv_your_api_key")

response = client.chat.completions.create(

    messages=[
        {"role": "user", "content": "Explain quantum computing in one sentence."}
    ],
```

```python
print(response.choices[0].message.content)
```

```typescript
import { createZorveus } from "@zorveus/sdk/vercel";
import { generateText } from "ai";

const zorveus = createZorveus({
  apiKey: "zrv_your_api_key",
});

async function main() {

main();
```

```go
package main

import (
	"context"
	"fmt"
	"github.com/sashabaranov/go-openai"
)

func main() {
	config := openai.DefaultConfig("zrv_your_api_key")
	config.BaseURL = "https://api.zorveus.com/v1"

	client := openai.NewClientWithConfig(config)
	resp, err := client.CreateChatCompletion(
		context.Background(),
		openai.ChatCompletionRequest{
			Model: "openai/gpt-4.1-mini",
			Messages: []openai.ChatCompletionMessage{
				{
					Role:    openai.ChatMessageRoleUser,
					Content: "Explain quantum computing in one sentence.",
				},
			},
		},
	)

	if err != nil {
		fmt.Printf("Error: %v\n", err)
		return
	}

	fmt.Println(resp.Choices[0].Message.Content)
}
```

```rust
use async_openai::{
    config::OpenAIConfig,
    types::{CreateChatCompletionRequestArgs, ChatCompletionRequestUserMessageArgs},
    Client,
};

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let config = OpenAIConfig::new()
        .with_api_base("https://api.zorveus.com/v1")
        .with_api_key("zrv_your_api_key");

    let client = Client::with_config(config);

    let request = CreateChatCompletionRequestArgs::default()
        .model("openai/gpt-4.1-mini")
        .messages([ChatCompletionRequestUserMessageArgs::default()
            .content("Explain quantum computing in one sentence.")
            .build()?
            .into()])
        .build()?;

    let response = client.chat().create(request).await?;
    println!("{}", response.choices[0].message.content.clone().unwrap_or_default());

    Ok(())
}
```

### Framework adapters

Framework adapters let you keep your existing OpenAI or Vercel AI SDK code while routing inference through Zorveus. They can attach product-user attribution. The gateway, not the adapter, enforces the connection’s caps, credit mode, and funding policy.

<CodeGroup titles={["Python OpenAI Adapter (zorveus[openai])", "TypeScript OpenAI Adapter (@zorveus/sdk/openai)", "TypeScript Vercel AI SDK (@zorveus/sdk/vercel)"]}>

```python
# pip install zorveus[openai]
from zorveus.openai import ZorveusOpenAI

# Drop-in wrapper for official OpenAI Python SDK
client = ZorveusOpenAI(
    api_key="zrv_your_api_key",
    external_user_id="usr_sara_101",
    display_name="Sara Connor"
)

response = client.chat.completions.create(
    model="openai/gpt-4.1-mini",
    messages=[{"role": "user", "content": "Hello!"}]
)
```

```typescript
// npm install @zorveus/sdk openai
import { ZorveusOpenAI } from "@zorveus/sdk/openai";

// Drop-in wrapper for official OpenAI TypeScript SDK
const openai = new ZorveusOpenAI({
  apiKey: "zrv_your_api_key",
  externalUserId: "usr_sara_101",
  displayName: "Sara Connor"
});

const completion = await openai.chat.completions.create({
  model: "openai/gpt-4.1-mini",
  messages: [{ role: "user", content: "Hello!" }]
});
```

| Surface | Production Endpoint | Usage |
| :--- | :--- | :--- |
| **Inference Gateway** | `https://api.zorveus.com/v1` | OpenAI-compatible inference (`/chat/completions`, `/models`, etc.) |
| **Product & Management API** | `https://api.zorveus.com` | Programmatic management with a service key (`zrv_svc_...`) |
| **Developer Dashboard** | `https://app.zorveus.com` | Web UI for workspace management, keys, wallets, and OAuth consent |
