# Provider Credentials

<ApiEndpoint method="POST" path="/provider-credentials" auth="service_key" />

Provider credentials store upstream AI model provider keys, encrypted at rest using AES-256-GCM.

<KeyInserter type="service" label="Service Key Inserter" placeholder="zrv_service_your_service_key" />

---

## Create a Provider Credential

<CodeGroup titles={["cURL", "Python"]}>

```bash
curl -X POST https://api.zorveus.com/provider-credentials \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer zrv_service_your_service_key" \
  -d '{
    "org_id": "org_startup_1048",
    "provider": "openai",
    "api_key": "sk-proj-sample_upstream_key_123456789",
    "model_policy": "openai/*",
    "priority": 10
  }'
```

```python
import requests

response = requests.post(
    "https://api.zorveus.com/provider-credentials",
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer zrv_service_your_service_key",
    },
    json={
        "org_id": "org_startup_1048",
        "provider": "openai",
        "api_key": "sk-proj-sample_upstream_key_123456789",
        "model_policy": "openai/*",
        "priority": 10,
    },
)

print(response.json())
```
