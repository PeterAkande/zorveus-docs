---
title: Provider credentials
description: Configure Bring Your Own Key credentials in the Zorveus dashboard.
---

Manage provider credentials in the Zorveus dashboard under **Provider Credentials**. Application code does not call a provider-credential API. Use a Zorveus API key for inference, not the upstream provider secret.

## Add a provider credential

1. Open your organization in the Zorveus dashboard.
2. Open **Provider Credentials**.
3. Select the provider and enter the credentials requested by the form.
4. Set the model policy and routing options shown in the dashboard.
5. Save the credential and check its validation status.

The dashboard lists supported providers and their required fields. Do not copy upstream secrets into application requests.

## Choose a routing mode

| Mode | Behavior |
| --- | --- |
| `auto_resolve` | The gateway may use the credential when its model policy matches. |
| `manual_grant_only` | The gateway uses the credential only for app connections that have an explicit grant. |
| `disabled` | The gateway does not resolve the credential. |

Configure routing and app-connection access in the dashboard. Lower `routing_priority` values are considered before higher values.

## Rotate or remove a credential

Use **Provider Credentials** in the dashboard to replace or remove upstream credentials. Check which app connections depend on a credential before removing it.

## Test inference

Select an available model from [the model catalog](https://www.zorveus.com/models). Send an inference request with your Zorveus API key and inspect usage in the dashboard.

For provider-specific requirements, see [Provider integrations](/providers/overview).
