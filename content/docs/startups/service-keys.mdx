# Service Keys

Service Keys (`zrv_service_...`) provide high-privilege programmatic access to the Zorveus Management API (`https://api.zorveus.com`).

<KeyInserter type="service" label="Service Key Inserter" placeholder="zrv_service_your_service_key" />

<Callout type="danger" title="Strict Backend-Only Credential">
  Service keys must NEVER be included in frontend code, client SDKs, mobile binaries, or client-rendered web pages. They possess administrative authority to manage users, spend budgets, and modify organization configurations.
</Callout>

---

## Allowed Operations

Service keys can execute the following management operations:
- Query, create, update, and search Product Users
- Issue, inspect, and revoke Product-User Credit Grants
- Query organization usage summaries and event logs
- Store and manage BYOK Provider Credentials
- Configure spending caps and rate limits
