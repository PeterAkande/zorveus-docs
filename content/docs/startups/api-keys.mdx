API keys (`zrv_...`) authenticate requests against the OpenAI-compatible gateway (`https://api.zorveus.com/v1`) and provider-native wire endpoints.

<Callout type="warning" title="Distinct from Service Keys">
  API keys (`zrv_...`) execute model inference and inspect connection spend. They cannot perform organization management. Programmatic organization administration requires a Service Key (`zrv_svc_...`). Never supply a Service Key to model inference endpoints.
</Callout>

## 1. Check Live Usage & Spend Cap

You can query the current spending cap, spent amount this period, remaining balance, and reset date directly using the API key itself. 

<Callout type="tip" title="Public CORS Enabled">
  `GET /inference-keys/usage` allows public CORS requests, making it safe to call directly from browser applications, IDE extensions, and client-side frontends.
</Callout>

<CodeGroup titles={["cURL", "Browser / Frontend", "TypeScript SDK", "Python SDK"]}>

```bash
curl -X GET "https://api.zorveus.com/inference-keys/usage" \
  -H "Authorization: Bearer zrv_your_api_key"
```

```javascript
// Safe to execute directly in browser applications
async function checkUsage() {
  const res = await fetch("https://api.zorveus.com/inference-keys/usage", {
    headers: {
      Authorization: "Bearer zrv_your_api_key",
    },
  });

  const data = await res.json();
  console.log("Remaining Balance ($):", data.remaining_balance);
  console.log("Spent this Month ($):", data.spent_this_period);
  console.log("Monthly Spend Cap ($):", data.spend_cap);
}
```

```typescript
import { Zorveus } from "@zorveus/sdk";

const client = new Zorveus({
  apiKey: "zrv_your_api_key",
});

const usage = await client.apiKeys.getUsage();
console.log("Remaining Balance:", usage.remaining_balance);
console.log("Reset Date:", usage.reset_at);
```

```python
import requests

response = requests.get(
    "https://api.zorveus.com/inference-keys/usage",
    headers={"Authorization": "Bearer zrv_your_api_key"},
)

usage = response.json()
print(f"Spent This Period: ${usage['spent_this_period']}")
print(f"Remaining Balance: {f'${usage[\"remaining_balance\"]}' if usage['remaining_balance'] else 'Uncapped'}")
```

## 2. One-Time Plaintext Display

When you generate or rotate an API key, the plaintext secret is displayed **only once**:

```text
zrv_live_9a8f7c2b4d1e6f0a5c3e7d9b2a4f6c8e
```

Zorveus stores only irreversible SHA-256 hashes of keys. If a key is lost, rotate or generate a new key.

---

## 3. Key Rotation Without Downtime

<Steps>
  <Step title="Create New Key">
    Under your App Connection, click **Create Secondary Key**.
  </Step>
  <Step title="Deploy to Production">
    Update your backend environment variables (`ZORVEUS_API_KEY`) with the new secret and deploy.
  </Step>
  <Step title="Revoke Old Key">
    Once traffic shifts, click **Revoke** on the previous key. Revocation is instantaneous across all edge gateway instances.
  </Step>
</Steps>
