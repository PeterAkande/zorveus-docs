A Zorveus API key (`zrv_...`) authenticates model requests against `https://api.zorveus.com/v1` and carries its own allowed models, spending cap, credit mode, and overrun policy.

## Which key do you need?

| Key type | Prefix | Where it runs | What it does |
| :--- | :--- | :--- | :--- |
| **API key** | `zrv_...` | Your backend | Calls models with that key's allowed models and spending rules. |
| **Routing key** | `zrv_route_...` | Your backend | Uses one secret to route requests across multiple plan keys via `X-Zorveus-Key-Alias`. See [Routing keys](/startups/routing-keys). |
| **Service key** | `zrv_svc_...` | Your backend | Reads and updates customer profiles, allowances, and credit grants on `https://api.zorveus.com`. Cannot call models. See [Service keys](/startups/service-keys). |
| **User OAuth token** | `zrv_usr_...` | Browser or backend | Calls models billed directly to a connected user's own Zorveus wallet. See [Connect user wallets](/oauth/overview). |

To route requests through your own OpenAI, Anthropic, or Gemini accounts instead of your Zorveus wallet, add upstream keys in the dashboard under [Provider keys (BYOK)](/startups/provider-credentials). Your code still sends your Zorveus API key (`zrv_...`).

## Create an API key

1. Open your **Business** organization in the [Zorveus dashboard](https://app.zorveus.com).
2. Open an app (or [create one](/startups/apps)) and go to **API Keys**.
3. Click **Create API Key**, copy the secret (`zrv_...`), and store it as `ZORVEUS_API_KEY` on your server. The raw secret is shown only once.

To make your first call, follow [Make your first API request](/getting-started/startup-quickstart). To enforce separate limits per customer, see [Configure product-user allowances](/startups/configure-product-user-allowances) and send `X-Zorveus-External-User-ID` with each request.

## Inspect key usage

Call `GET https://api.zorveus.com/inference-keys/usage` to read the key's current spend, cap, remaining balance, and reset time:

<CodeGroup titles={["TypeScript (@zorveus/sdk)", "Python (zorveus)", "cURL"]}>

```typescript
import { Zorveus } from "@zorveus/sdk";

const client = new Zorveus({
  apiKey: process.env.ZORVEUS_API_KEY!,
});

const usage = await client.getUsage();
console.log(`Spent $${usage.spent_this_period} of $${usage.spend_cap}`);
```

```python
import os
from zorveus import Zorveus

client = Zorveus(api_key=os.environ["ZORVEUS_API_KEY"])
try:
    usage = client.get_usage()
    print(f"Spent ${usage.spent_this_period} of ${usage.spend_cap}")
finally:
    client.close()
```

```bash
curl --fail-with-body https://api.zorveus.com/inference-keys/usage \
  -H "Authorization: Bearer $ZORVEUS_API_KEY"
```

</CodeGroup>

Example response:

```json
{
  "status": "active",
  "app_id": "app_123",
  "app_connection_id": "appcon_123",
  "currency": "USD",
  "period": "monthly",
  "spend_cap": "50.000000000000",
  "spent_this_period": "12.500000000000",
  "remaining_balance": "37.500000000000",
  "reset_at": "2026-12-01T00:00:00Z"
}
```

See [Key usage](/api-reference/usage) for nullable fields and status values. This endpoint returns key-level spend across all traffic on that key, not an individual customer's remaining balance. To read a customer's allowance, use [Check available allowance](/startups/check-allowance).

## Rotate an API key

Rotate a key without downtime:

1. Create a replacement API key in the dashboard with the same policy.
2. Deploy the new key to your backend and verify a live request succeeds.
3. Revoke the old key in the dashboard.

## Keep company keys on your server

The gateway supports CORS for browser-based OAuth apps, not for embedding company API keys in frontend bundles. Keep `zrv_...` Business keys on your backend server. If you want to call models directly from the browser, use a connected user's OAuth token (`zrv_usr_...`) via [Connect user wallets](/oauth/overview).
