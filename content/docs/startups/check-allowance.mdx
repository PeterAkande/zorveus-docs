---
title: Show a customer's balance
description: Read a customer's remaining AI allowance in dollars or credits and show when it resets.
---

Show customers how much AI they have left, such as "$2 remaining" or "200 credits left." Read their balance from your backend using their customer ID. This works with free allowances and paid plans.

## 1. Read the balance

Save these values on your server:

- `ZORVEUS_SERVICE_KEY`: Create a [service key](/startups/service-keys) with `product_users:read` permission. This key authorizes the balance read.
- `ZORVEUS_API_KEY`: Use the inference key you send that customer's AI requests with. This tells Zorveus which allowance settings to use. [Set a customer limit](/startups/configure-product-user-allowances) if you have not configured one yet.
- `ZORVEUS_APP_ID`: Copy the app ID from your app in the [dashboard](https://app.zorveus.com). Use the same app as the inference key.

Install `@zorveus/sdk` with `npm install @zorveus/sdk` for TypeScript or `zorveus` with `pip install zorveus` for Python.

Replace `customer_42` below with the ID from your backend's signed-in user session. Keep both keys on your server. The examples create the customer record if it does not exist, so you can show a starting balance before their first AI request.

<CodeGroup titles={["TypeScript (@zorveus/sdk)", "Python (zorveus)", "cURL"]}>

```typescript
import { ZorveusServiceClient } from "@zorveus/sdk";

const service = new ZorveusServiceClient({
	apiKey: process.env.ZORVEUS_SERVICE_KEY!,
});

const user = await service.productUsers.getByExternalId({
	appId: process.env.ZORVEUS_APP_ID!,
	externalUserId: "customer_42",
	inferenceKey: process.env.ZORVEUS_API_KEY!,
	upsertIfMissing: true,
});

const availableUsd = user.allowance?.available_allowance ?? null;
console.log(availableUsd === null ? "Balance unavailable" : `$${availableUsd} remaining`);
console.log("Resets at:", user.allowance?.period_end ?? null);
```

```python
import os
from zorveus import ZorveusServiceClient

service = ZorveusServiceClient(api_key=os.environ["ZORVEUS_SERVICE_KEY"])
try:
	user = service.product_users.get_by_external_id(
		app_id=os.environ["ZORVEUS_APP_ID"],
		external_user_id="customer_42",
		inference_key=os.environ["ZORVEUS_API_KEY"],
		upsert_if_missing=True,
	)

	available_usd = user.allowance.available_allowance if user.allowance else None
	print("Balance unavailable" if available_usd is None else f"${available_usd} remaining")
	print("Resets at:", user.allowance.period_end if user.allowance else None)
finally:
	service.close()
```

```bash
curl --fail-with-body --get https://api.zorveus.com/product-users/by-external-id \
	-H "Authorization: Bearer $ZORVEUS_SERVICE_KEY" \
	-H "X-Zorveus-Inference-Key: $ZORVEUS_API_KEY" \
	-H "X-Zorveus-Upsert-Product-User: true" \
	--data-urlencode "app_id=$ZORVEUS_APP_ID" \
	--data-urlencode "external_user_id=customer_42"
```

</CodeGroup>

For a new customer with a $2 monthly allowance and no usage or extra credits, the SDK examples print `$2.000000000000 remaining` and the reset date. cURL returns the customer profile.

## 2. Show dollars or credits

Choose the field that matches how your app uses allowances:

| Your app uses | Read |
| --- | --- |
| USD allowances | `allowance.available_allowance` |
| Credit units | `allowance.remaining_credit_units` |

Both totals include the remaining recurring allowance and usable extra credits. Send the selected value from your backend to your app. Refresh the balance after AI requests or credit purchases.

Use `allowance.period_end` for the reset date. It is a UTC timestamp, or `null` when no reset date is available.

### Show the balance in credits

If your app uses credits, [set your app's conversion rate](/getting-started/integrate-your-product#use-credits-in-your-product). At 100 credits per $1, the $2 allowance above gives the customer 200 credits. Zorveus keeps the underlying allowance in USD and returns the credit units for you.

Using the `user` returned above:

<CodeGroup titles={["TypeScript (@zorveus/sdk)", "Python (zorveus)"]}>

```typescript
const creditsLeft = user.allowance?.remaining_credit_units ?? null;
console.log(creditsLeft === null ? "Balance unavailable" : `${creditsLeft} credits left`);
```

```python
credits_left = user.allowance.remaining_credit_units if user.allowance else None
print("Balance unavailable" if credits_left is None else f"{credits_left} credits left")
```

</CodeGroup>

Keep the returned decimal strings and format them for display, such as "200 credits left." Use the returned credit total instead of multiplying the USD balance yourself, because individual grants can have different saved conversion rates. For a working app, see [Write Room](/code-labs/write-room-saas).

## 3. Handle missing or exhausted balances

| Returned state | What your app should do |
| --- | --- |
| Positive balance | Show the remaining amount. The next request can still exceed that amount or fail another access check. |
| Zero balance | Show that the allowance is used up. Offer a reset date or extra credits if your product supports them. |
| Missing allowance or selected balance field | Show "Balance unavailable." A credit-unit balance can be missing when a positive allowance has no conversion rate. Missing data does not mean the balance is zero. |
| `status: "blocked"` | Show that AI access is blocked, even if there is a remaining balance. |

Use decimal arithmetic when comparing amounts. For example, `"0.000000000000"` is zero, even though it is not the string `"0"`.

You do not need to read the balance before every AI request. When allowance enforcement is enabled, Zorveus checks the allowance during model requests. This balance read is for your app's display and logic.
