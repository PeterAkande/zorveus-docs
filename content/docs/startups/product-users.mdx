# Product Users

<ApiEndpoint method="PUT" path="/product-users/by-external-id" auth="service_key" />

Product Users are your customers. You can create or update them inline during inference or manage them explicitly using your Organization Service Key.

## Upsert Product User by External ID

<CodeGroup titles={["cURL", "Python", "TypeScript"]}>

```bash
curl -X PUT https://api.zorveus.com/product-users/by-external-id \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer zrv_service_your_service_key" \
  -d '{
    "org_id": "org_startup_1048",
    "external_user_id": "usr_cust_94821",
    "name": "Sarah Connor",
    "email": "sarah.connor@example.com",
    "metadata": {
      "plan": "enterprise_seat",
      "company": "Cyberdyne Systems"
    }
  }'
```

```python
import requests

response = requests.put(
    "https://api.zorveus.com/product-users/by-external-id",
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer zrv_service_your_service_key",
    },
    json={
        "org_id": "org_startup_1048",
        "external_user_id": "usr_cust_94821",
        "name": "Sarah Connor",
        "email": "sarah.connor@example.com",
        "metadata": {
            "plan": "enterprise_seat",
            "company": "Cyberdyne Systems",
        },
    },
)

print(response.json())
```

```typescript
async function upsertProductUser() {
  const response = await fetch("https://api.zorveus.com/product-users/by-external-id", {
    method: "PUT",
    headers: {
      "Content-Type": "application/json",
      Authorization: "Bearer zrv_service_your_service_key",
    },
    body: JSON.stringify({
      org_id: "org_startup_1048",
      external_user_id: "usr_cust_94821",
      name: "Sarah Connor",
      email: "sarah.connor@example.com",
    }),
  });

  return await response.json();
}
```
