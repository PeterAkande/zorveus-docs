title: Manage customer profiles
description: Look up a customer's profile or save their name, email, and account metadata from your backend.
---

Keep customer details in Zorveus up to date, such as their name and account metadata. Use the same customer ID you send with their AI requests.

Zorveus creates a record on their first AI request when you include their customer ID. You can also create or update the record from your backend. The SDK calls these records `productUsers` in TypeScript and `product_users` in Python.

## Look up a customer

Create a [service key](/startups/service-keys) with `product_users:read` permission and save it as `ZORVEUS_SERVICE_KEY`. Copy your app ID from the [dashboard](https://app.zorveus.com) and save it as `ZORVEUS_APP_ID`. Keep the service key on your server.

Install `@zorveus/sdk` with `npm install @zorveus/sdk` for TypeScript or `zorveus` with `pip install zorveus` for Python. Replace `customer_42` below with the ID from your backend's signed-in user session.

<CodeGroup titles={["TypeScript (@zorveus/sdk)", "Python (zorveus)", "cURL"]}>

```typescript
import { ZorveusServiceClient } from "@zorveus/sdk";

const service = new ZorveusServiceClient({
	apiKey: process.env.ZORVEUS_SERVICE_KEY!,
});

const user = await service.productUsers.getByExternalId({
	appId: process.env.ZORVEUS_APP_ID!,
	externalUserId: "customer_42",
});

console.log(user.external_user_id);
console.log(user.display_name ?? "Name not set");
```

```python
import os
from zorveus import ZorveusServiceClient

service = ZorveusServiceClient(api_key=os.environ["ZORVEUS_SERVICE_KEY"])
try:
	user = service.product_users.get_by_external_id(
		app_id=os.environ["ZORVEUS_APP_ID"],
		external_user_id="customer_42",
	)
	print(user.external_user_id)
	print(user.display_name if user.display_name is not None else "Name not set")
finally:
	service.close()
```

```bash
curl --fail-with-body --get https://api.zorveus.com/product-users/by-external-id \
	-H "Authorization: Bearer $ZORVEUS_SERVICE_KEY" \
	--data-urlencode "app_id=$ZORVEUS_APP_ID" \
	--data-urlencode "external_user_id=customer_42"
```

</CodeGroup>

For an existing record without a saved name, the SDK examples print:

```text
customer_42
Name not set
```

The read returns the profile directly. It includes `external_user_id`, `display_name`, `status`, and `metadata`. Email is returned as `email_hash`, so keep the original email address in your app. cURL returns the full JSON profile.

If the record does not exist, lookup returns HTTP `404`. Create it with the example below. To create a record during a balance read and show its starting allowance, follow [Show a customer's balance](/startups/check-allowance).

## Create or update a customer

Use a service key with `product_users:write` permission. This also permits reads. The same call creates a missing customer record or updates an existing one with the same app ID and customer ID.

Include the name, email, and metadata values you want to keep. Omitting one of these fields clears its saved value. Metadata is replaced rather than merged. Read these values from your app's customer record, including the original email address.

This example saves Alex's profile with an `account_type` value in metadata. Use metadata for your own account details. It does not change model access or authorize a paid plan.

<CodeGroup titles={["TypeScript (@zorveus/sdk)", "Python (zorveus)", "cURL"]}>

```typescript
import { ZorveusServiceClient } from "@zorveus/sdk";

const service = new ZorveusServiceClient({
	apiKey: process.env.ZORVEUS_SERVICE_KEY!,
});

const result = await service.productUsers.createOrUpdate({
	appId: process.env.ZORVEUS_APP_ID!,
	externalUserId: "customer_42",
	displayName: "Alex Rivera",
	email: "alex@example.com",
	metadata: { account_type: "individual" },
});

console.log(result.created ? "Customer created" : "Customer updated");
console.log(result.product_user.display_name);
```

```python
import os
from zorveus import ZorveusServiceClient

service = ZorveusServiceClient(api_key=os.environ["ZORVEUS_SERVICE_KEY"])
try:
	result = service.product_users.create_or_update(
		app_id=os.environ["ZORVEUS_APP_ID"],
		external_user_id="customer_42",
		display_name="Alex Rivera",
		email="alex@example.com",
		metadata={"account_type": "individual"},
	)
	print("Customer created" if result.created else "Customer updated")
	print(result.product_user.display_name)
finally:
	service.close()
```

```bash
curl --fail-with-body -X PUT https://api.zorveus.com/product-users/by-external-id \
	-H "Authorization: Bearer $ZORVEUS_SERVICE_KEY" \
	-H "Content-Type: application/json" \
	-d '{
		"app_id": "app_123",
		"external_user_id": "customer_42",
		"display_name": "Alex Rivera",
		"email": "alex@example.com",
		"metadata": {"account_type": "individual"}
	}'
```

</CodeGroup>

Replace `app_123` in the cURL body with your app ID. Each example saves the same profile. For an existing record, the SDK examples print:

```text
Customer updated
Alex Rivera
```

`result.created` is `true` for a new record and `false` for an existing one. The saved profile is in `result.product_user`. Sending the same app ID and customer ID again updates that record rather than creating a duplicate.
