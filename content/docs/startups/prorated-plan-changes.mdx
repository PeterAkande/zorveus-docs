---
title: Prorate AI allowances on plan upgrades
description: Set the plan-change policy once and prorate AI allowance increases when customers upgrade.
---

Proration adjusts the extra AI allowance based on how much of the current cycle is left. Half a cycle left means half the allowance increase

[Configure both plan connections](/startups/configure-product-user-allowances) with active daily or monthly caps. Use the same period and currency

## 1. Send the policy

Send the policy on the first request and on later requests while the customer stays on a plan or upgrades. For a downgrade, omit the policy from the switching request; Zorveus does not prorate decreases. Use your app's [inference API key](/startups/api-keys)

<Tabs items={["Header", "Request body"]}>
<Tab title="Header">

```bash
curl https://api.zorveus.com/v1/chat/completions \
	-H "Authorization: Bearer $PLAN_API_KEY" \
	-H "Content-Type: application/json" \
	-H "X-Zorveus-External-User-ID: customer_123" \
	-H "X-Zorveus-Allowance-Change-Policy: prorate_increase" \
	-d '{"model":"YOUR_ALLOWED_MODEL","messages":[{"role":"user","content":"Hello"}]}'
```

</Tab>
<Tab title="Request body">

```json
{
	"model": "YOUR_ALLOWED_MODEL",
	"messages": [{"role": "user", "content": "Hello"}],
	"metadata": {
		"external_user_id": "customer_123",
		"product_user": {"allowance_change": "prorate_increase"}
	}
}
```

</Tab>
</Tabs>

The body value takes precedence over the header. Zorveus records the initial connection without proration

## 2. Switch the plan's API key

When the customer upgrades, use the API key for the new plan's connection. Keep the same user ID and [allowance anchor](/startups/allowance-periods)

A $10 to $50 upgrade increases the allowance by $40. Halfway through the cycle, the customer gets $20 extra:

```text
Current-cycle allowance = $10 + ($50 - $10) × 0.5 = $30
Remaining after $8 used = $30 - $8 = $22
```

Requests with the same connection reuse the saved allowance. At renewal, the full configured $50 allowance applies

## 3. Read the remaining allowance

Fetch the [product user](/api-reference/product-users#get-product-user-by-external-id) with your service key:

```bash
curl --get https://api.zorveus.com/product-users/by-external-id \
	-H "Authorization: Bearer $SERVICE_API_KEY" \
	--data-urlencode "app_id=$APP_ID" \
	--data-urlencode "external_user_id=customer_123"
```

Display `allowance.available_allowance` as the remaining balance. Use `allowance.period_end` for the renewal date
