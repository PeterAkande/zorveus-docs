- [Make your first API request](/getting-started/startup-quickstart): Send your first model request in five minutes.
- [Manage customer AI usage](/getting-started/integrate-your-product): Backend integration for plans, allowance checks, and payment webhooks.
- [Let users fund their AI usage](/getting-started/oauth-app-quickstart): User-funded PKCE authorization flow.
- [Provider credentials (BYOK)](/startups/provider-credentials): Optional upstream routing through your own OpenAI, Anthropic, or Gemini account.

- [REST API reference](/api-reference/overview): Full HTTP contracts and SDK examples for product users, usage, models, and OAuth.
