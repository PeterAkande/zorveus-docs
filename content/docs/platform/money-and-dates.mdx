---
title: Money and dates
description: Preserve decimal amounts and timezone-aware timestamps across clients.
---

Zorveus returns monetary amounts as decimal strings, such as `"10.00"` or `"0.000150"`. Parse them with a decimal or fixed-point library when you need arithmetic. Do not convert them to binary floating point for billing or reconciliation.

Request schemas may accept a JSON number for a decimal field, but sending a string prevents the client from rounding the value before serialization.

Timestamps use ISO 8601 and include a timezone offset, for example:

```text
2026-08-13T20:45:00Z
```

Send timezone-aware values for filters and date boundaries. Treat returned timestamps as instants, then convert them for display in the user’s timezone.
