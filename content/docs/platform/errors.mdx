# Error Handling & Error Codes

Zorveus provides structured, actionable error responses across both API surfaces.

---

## 1. Product & Management API Errors

Endpoints on `https://api.zorveus.com` return standard JSON error envelopes:

```json
{
  "error": {
    "code": "invalid_parameter",
    "message": "The external_user_id field cannot exceed 128 characters.",
    "request_id": "req_84102941"
  }
}
```

---

## 2. Gateway Inference Errors

Endpoints on `https://api.zorveus.com/v1` return OpenAI SDK-compatible error objects:

```json
{
  "error": {
    "message": "Spending cap of $50.00 for connection con_1048 exceeded.",
    "type": "insufficient_quota",
    "code": "cap_exceeded",
    "param": null
  }
}
```

---

## Canonical Error Codes

| Code | HTTP Status | Meaning | Actionable Resolution |
| :--- | :--- | :--- | :--- |
| `invalid_api_key` | 401 | The inference key is missing or revoked | Rotate or generate a new key in dashboard |
| `insufficient_balance` | 402 | Wallet balance depleted | Top up wallet or connect BYOK credentials |
| `cap_exceeded` | 429 | Spending cap limit reached | Increase connection or org cap in dashboard |
| `model_not_allowed` | 403 | Model not in connection policy | Update allowed model wildcard settings |
| `rate_limit_exceeded` | 429 | Upstream or Zorveus RPM exceeded | Implement exponential backoff retry |
