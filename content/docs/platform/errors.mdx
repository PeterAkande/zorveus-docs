---
title: Error handling
description: Handle product API and OpenAI-compatible gateway errors without relying on message text.
---

Product and management routes return a structured Zorveus error with a stable `code` and human-readable `message`. Gateway routes return an OpenAI-compatible `error` object. Log the request identifier when one is available.

Endpoints on `https://api.zorveus.com` return standard JSON error envelopes:

```json
{
  "error": {
    "code": "zorveus_invalid_parameter",
    "message": "The external_user_id field cannot exceed 128 characters.",
    "request_id": "req_84102941"
  }
}
```

Common gateway codes include:

| Code | Typical status | Response |
| --- | --- | --- |
| `zorveus_malformed_or_missing_key` | 401 | Send a Bearer API key. |
| `zorveus_unknown_key` | 401 | Check that the key belongs to this environment. |
| `zorveus_key_inactive` | 401 | Replace a revoked or inactive key. |
| `zorveus_model_not_allowed` | 403 | Request a model allowed by the connection and key. |
| `zorveus_unsupported_model` | 400 | Discover a currently available model with `GET /v1/models`. |
| `zorveus_reservation_insufficient_balance` | 402 | Add wallet funds or correct the funding route. |
| `zorveus_cap_exceeded` | 429 | Increase the applicable cap or wait for its period to reset. |
| `zorveus_product_user_credits_insufficient` | 403 | Product user has exhausted allocated credits. Grant credits or switch credit mode. |
| `zorveus_product_user_credits_required` | 400 | Connection enforces user credits. Pass `metadata.external_user_id`. |

Use the code for program logic. Message wording can change. Retry only transient failures and rate limits; do not retry authentication, policy, or balance failures without changing the request or account state.

See [Troubleshooting](/resources/troubleshooting) for diagnosis by symptom.
