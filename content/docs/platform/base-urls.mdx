---
title: Base URLs and environments
description: Use the correct production host for inference, management, dashboard, and OAuth traffic.
---

| Surface | Base URL | Use |
| --- | --- | --- |
| Inference gateway | `https://api.zorveus.com/v1` | OpenAI-compatible model requests and model discovery. |
| Product and management API | `https://api.zorveus.com` | Service-key and dashboard-backed management routes. |
| Dashboard and browser authorization | `https://app.zorveus.com` | Dashboard UI, sign-in, consent, and the browser authorization URL. |
| Documentation | `https://docs.zorveus.com` | Developer documentation. |

OAuth token exchange and revocation are API requests under `https://api.zorveus.com/oauth`. Start authorization in the browser at `https://app.zorveus.com/oauth/authorize`.

Do not add `/v1` to management routes. Do add it when configuring an OpenAI-compatible SDK base URL.
