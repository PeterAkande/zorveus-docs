---
title: Lists and pagination
description: Read product-user grant lists without assuming a shared cursor contract.
---

List formats depend on the endpoint. The application-facing product-user grant list returns `credit_grants` and accepts `limit` from 1 to 1000, with a default of 100. It does not return `next_cursor` or `has_more`, and it does not accept a cursor

```json
{
	"credit_grants": []
}
```

Use `status` and `source` to narrow the grant list. See [List credit grants](/api-reference/product-users#list-credit-grants). A limited result is not a complete credit ledger

The key-scoped model list returns `data`. The public catalog returns `items`. Do not assume a generic `items` wrapper or dashboard pagination fields in your application's client
