# Usage Filters & Time-Series

<ApiEndpoint method="GET" path="/dashboard-api/usage/events" auth="dashboard_session" />

Filter usage records by multiple simultaneous dimensions:
- `start_date` & `end_date`: ISO 8601 timestamps
- `app_id`: Filter to a specific application
- `model`: Filter to a specific model family (e.g. `openai/gpt-4.1-mini`)
- `product_user_id`: Filter to an individual customer
- `billing_mode`: Filter by `wallet_funded` or `byok`
