---
title: Usage analytics
description: Query raw usage events, time-series totals, and app-connection summaries.
---

You can view your organization's usage events, time-series totals, and app-connection summaries via the Zorveus dashboard . Usage events are recorded for every request that consumes a Zorveus resource on the organization workspace. The usage event includes the request's metadata, model, provider, and billing mode.
Costs are returned as decimal strings. `provider_cost` and `sell_cost` serve different purposes, especially for BYOK requests. See [BYOK cost accounting](/wallet-and-billing/byok-costs).
