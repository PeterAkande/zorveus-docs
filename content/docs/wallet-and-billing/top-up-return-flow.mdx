---
title: Confirm a wallet top-up
description: Treat a checkout return as a status page rather than payment proof.
---

After checkout, the dashboard displays the top-up status. Zorveus verifies provider payment information before crediting wallet funds. A browser redirect alone does not prove payment or create customer credits

Wait for the credited balance or the signed `wallet.payment_credited` webhook before treating the top-up as available. Handle pending and failed payments explicitly. The webhook identifies a Zorveus organization wallet purchase, not a payment made to your own application

See [Webhooks](/platform/webhooks) for verification and [Billing integration](/startups/billing-integration) for customer purchases
