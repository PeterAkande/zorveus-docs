# Wallet Top-Ups

Top up wallet balances directly from the Zorveus dashboard using card or bank transfers.

---

## Supported Payment Methods

- Credit / Debit Cards (Visa, Mastercard, American Express)
- Supported currencies are charged directly without automatic currency conversion.
- Webhook confirmations update the wallet balance in real time upon bank settlement.
