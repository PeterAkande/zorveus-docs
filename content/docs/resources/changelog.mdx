## August 2026

- Added organization outbound webhooks with HMAC-SHA256 verification, delivery logs, and manual retries.
- Documented product-user credit grants, idempotent `external_reference` retries, and the four credit enforcement modes.
- Consolidated user-funded OAuth app guides, spending cap policies, test users, app review, and revocation flows.
- Added guides for Responses API, streaming, tool calling, embeddings, rerank, images, audio, moderation, and realtime audio.
- Added application API reference pages for product users, OAuth, model discovery, and key usage.

Model availability and provider options can change independently of release notes. Use `GET /v1/models` to check models enabled for your API key, and check **Provider Credentials** in the dashboard for active BYOK providers.
