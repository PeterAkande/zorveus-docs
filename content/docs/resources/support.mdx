---
title: Support and security reports
description: Get integration help, report a vulnerability, or check service status.
---

- Email `support@zorveus.com` for integration help. Include the route, HTTP status, stable error code, request identifier, SDK and version, and a minimal redacted example.
- Email `security@zorveus.com` for suspected vulnerabilities. Do not include live API keys, client secrets, provider credentials, session cookies, or personal data.
- Check [status.zorveus.com](https://status.zorveus.com) for service availability and incident updates.

For common integration failures, start with [Troubleshooting](/resources/troubleshooting).
