---
title: Support and security reports
description: Contact support for integration issues, report security vulnerabilities, or check live service status.
---

- **Integration support**: Email `support@zorveus.com` with the endpoint, HTTP status, `error.code`, `x-zorveus-request-id`, SDK version, and a minimal redacted reproduction.
- **Security reports**: Email `security@zorveus.com` for suspected vulnerabilities. Never include live API keys, client secrets, BYOK provider credentials, session cookies, or personal data.
- **Service status**: Check [status.zorveus.com](https://status.zorveus.com) for live availability and incident updates.

For common error codes and fixes, start with [Troubleshooting](/resources/troubleshooting).
