## Starter Kits

- **[Next.js AI Chatbot with Zorveus](https://github.com/zorveus/example-nextjs-chatbot)**: Full-stack Next.js App Router template with streaming responses, product-user attribution, and BYOK settings.
- **[Python FastAPI Gateway Integration](https://github.com/zorveus/example-fastapi-backend)**: Backend server using Organization Service Keys for credit grants and product user upserts.
- **[OAuth PKCE React App](https://github.com/zorveus/example-oauth-pkce-client)**: Single Page App demonstrating OAuth 2.0 PKCE login with user wallet authorization.
