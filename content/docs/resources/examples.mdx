The inference guides include OpenAI SDK, native SDK, and direct HTTP examples. The [API reference](/api-reference/overview) covers application endpoints for product users, OAuth, models, and key usage

Before copying a model ID, call `GET /v1/models` with the key you plan to use. For provider configuration, use the supported fields shown under **Provider Credentials** in the dashboard
