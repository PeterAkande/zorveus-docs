## How routing selects a credential

The gateway considers active credentials whose model policy matches the request. `auto_resolve` credentials can participate automatically. `manual_grant_only` credentials require an active grant to the app connection. Lower routing-priority numbers are considered before higher numbers.

If `auto_fallback_to_wallet` is enabled and the wallet can fund the request, the gateway can add wallet-funded routing after eligible provider credentials. Successful BYOK usage records the provider cost and can also record a configured Zorveus platform fee.

## Verify a provider

1. Read the runtime provider catalog.
2. Create and validate the credential.
3. Confirm its model policy and routing mode.
4. Grant it to the app connection when the mode requires a grant.
5. List models with the inference key.
6. Send a controlled inference request and inspect the usage event.

A provider route or wildcard alone is not evidence that every upstream model is available.
