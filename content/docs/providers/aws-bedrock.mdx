description: Check and configure the runtime credential contract for AWS Bedrock routes.

Bedrock support depends on the provider credential catalog and the deployed model routes.

---

## Configuration

- Typical provider ID: `bedrock`
- Typical model policy: `bedrock/*`

Call `GET /provider-credentials/providers` before creating the credential. Use the returned secret kinds and required configuration fields as the contract. Do not place separate AWS fields into a request unless the catalog documents that shape.

AWS authentication can use access keys, sessions, roles, or workload identity. The public Zorveus credential request accepts only the forms listed by the runtime catalog. If `bedrock` is absent, the deployment does not currently expose a supported Bedrock credential flow.

Choose only models returned by `GET /v1/models` for the API key.
