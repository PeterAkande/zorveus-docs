Bedrock support depends on the provider credential catalog and the deployed model routes.

---

## Configuration

- Typical provider ID: `bedrock`
- Typical model policy: `bedrock/*`

Open **Provider Credentials** in the dashboard and check whether AWS Bedrock is available. Use the authentication options and fields shown in the form.

Manage provider credentials in the Zorveus dashboard under **Provider Credentials**. Application code does not call a provider-credential API. Use a Zorveus API key for inference, not the upstream provider secret.

AWS authentication can use access keys, sessions, roles, or workload identity. Use only the forms supported by the dashboard. If AWS Bedrock is absent, you cannot configure a Bedrock credential in that deployment.

Choose only models returned by `GET /v1/models` for the API key.
