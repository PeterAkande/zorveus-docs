# AWS Bedrock Provider Setup

Connect AWS Bedrock credentials (`aws_access_key_id`, `aws_secret_access_key`, `aws_region_name`) to Zorveus.

---

## Configuration

- **Provider Name**: `bedrock`
- **Model Wildcard**: `bedrock/*`
- **Example Model**: `bedrock/anthropic.claude-3-7-sonnet-20250219-v1:0`
