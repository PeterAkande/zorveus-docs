title: OpenRouter provider setup
description: Connect OpenRouter API keys to access DeepSeek, Llama 3, and open-weights models.
---

Open **Provider Credentials** in the dashboard and select OpenRouter if it is available. Enter your OpenRouter API key in the form.

Manage provider credentials in the Zorveus dashboard under **Provider Credentials**. Application code does not call a provider-credential API. Use a Zorveus API key for inference, not the upstream provider secret.


---

## Configuration

- Provider ID: `openrouter`
- Secret kind: `api_key`
- Typical model policy: `openrouter/*`

The OpenRouter model catalog changes independently from Zorveus. Use `GET /v1/models` to select a model available to the API key. Do not copy a model slug from the upstream catalog unless the Zorveus model endpoint returns it.

OpenRouter can route to several upstream providers. Provider identity, pricing, context limits, and content handling can vary by model route. Review the upstream model details before sending sensitive or regulated data.
