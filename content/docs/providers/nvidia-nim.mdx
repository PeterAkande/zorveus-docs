Use an NVIDIA API Catalog or NIM credential when the runtime provider catalog lists `nvidia_nim`.

---

## Configuration

- Canonical provider ID: `nvidia_nim`
- Accepted aliases: `nvidia` and `nim`
- Secret kind: `api_key`

Use the canonical ID in new integrations. Query `GET /provider-credentials/providers` for the current provider label and requirements, then choose model names from `GET /v1/models`.

Hosted NVIDIA endpoints and self-hosted NIM deployments can require different configuration. The current public credential catalog is the authority for fields accepted by Zorveus. Do not infer endpoint configuration from the model name.
