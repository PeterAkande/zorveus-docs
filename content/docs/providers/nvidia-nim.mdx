Use an NVIDIA API Catalog or NIM credential when NVIDIA NIM is available in the dashboard.

---

## Configuration

- Canonical provider ID: `nvidia_nim`
- Accepted aliases: `nvidia` and `nim`
- Secret kind: `api_key`

Open **Provider Credentials** in the dashboard and select NVIDIA NIM. Enter the credentials and configuration requested by the form.

Manage provider credentials in the Zorveus dashboard under **Provider Credentials**. Application code does not call a provider-credential API. Use a Zorveus API key for inference, not the upstream provider secret.

Hosted NVIDIA endpoints and self-hosted NIM deployments can require different configuration. The dashboard form lists the supported configuration fields. Do not infer endpoint configuration from the model name.
