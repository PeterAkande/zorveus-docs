Azure credentials require both a secret and deployment configuration.

---

## Configuration

- Provider ID: `azure`
- Secret kinds: `api_key` or `azure_ad_token`
- Required `provider_config` fields: `api_base` and `api_version`
- Typical model policy: `azure/*`

Open **Provider Credentials** in the dashboard and select Azure OpenAI. Enter the key or Azure AD token, endpoint, and API version requested by the form.

Manage provider credentials in the Zorveus dashboard under **Provider Credentials**. Application code does not call a provider-credential API. Use a Zorveus API key for inference, not the upstream provider secret.

The configured Azure deployment names must match the model routing configuration. Confirm them with a controlled request instead of assuming that an OpenAI public model name maps to the deployment.
