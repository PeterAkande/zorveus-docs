title: Install and update the CLI
description: Install a prebuilt Zorveus CLI binary on macOS, Linux, or Windows, update it with zorveus update, and configure shell completion.
---

You do not need Go or a source checkout to run `zorveus`. Prebuilt binaries are published through [Zorveus CLI releases](https://github.com/zorveus/zorveus-cli/releases).

---

## macOS and Linux

```sh
curl -fsSL https://zorveus.com/install.sh | sh
```

The installer detects macOS or Linux and x86-64 or ARM64, verifies the SHA-256 checksum, and installs `zorveus` to `~/.local/bin` without `sudo`. Linux binaries are built without cgo, so they do not depend on glibc or musl.

You need `curl`, CA certificates, and either `sha256sum` or `shasum`.

The installer also sets up tab completion automatically for zsh, bash, or fish based on `$SHELL`. Open a new terminal after installing so completion loads. To choose a shell explicitly or skip completion:

```sh
curl -fsSL https://zorveus.com/install.sh | sh -s -- --shell zsh
curl -fsSL https://zorveus.com/install.sh | sh -s -- --no-completion
```

If `zorveus` is not found in your current terminal, add `~/.local/bin` to your `PATH`:

```sh
export PATH="$HOME/.local/bin:$PATH"
zorveus --help
```

Add that `export PATH` line to `~/.zshrc` or `~/.bashrc` to keep it in future terminals.

To inspect the script, pin a version, or install into a custom directory:

```sh
curl -fsSL https://zorveus.com/install.sh -o install-zorveus.sh
sh install-zorveus.sh --help
sh install-zorveus.sh --version v0.1.0 --bin-dir "$HOME/.local/bin"
```

A failed download or checksum check leaves your existing binary untouched. Reinstalling refreshes completion without duplicating startup lines and preserves your saved logins.

## Windows

Run this command in PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://zorveus.com/install.ps1 | iex"
```

The installer supports Windows PowerShell 5.1 and PowerShell 7. It detects x86-64 or ARM64, verifies the SHA-256 checksum, and installs `zorveus.exe` into `%LOCALAPPDATA%\Zorveus\bin` without administrator access. It adds that directory to your user `Path` automatically.

Open a new terminal, then check the installation:

```powershell
zorveus --help
```

If `zorveus` is not found, restart your terminal application so it picks up the updated PATH. If the installer reports that PATH setup failed, add `%LOCALAPPDATA%\Zorveus\bin` to your user `Path` in Windows Environment Variables.

To inspect the script, pin a version, or install into a custom directory, download the script first:

```powershell
Invoke-WebRequest https://zorveus.com/install.ps1 -OutFile install-zorveus.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\install-zorveus.ps1 -Help
powershell -NoProfile -ExecutionPolicy Bypass -File .\install-zorveus.ps1 -Version v0.1.0 -BinDir "$env:LOCALAPPDATA\Zorveus\bin"
```

Replace `v0.1.0` with the release you want to install. A failed download or checksum check preserves your existing executable. Reinstalling preserves your saved logins and avoids duplicate PATH entries. Close running Zorveus processes before reinstalling if Windows reports that the executable is in use.

Login and secret storage require an available, unlocked OS credential store: Keychain on macOS, Secret Service on Linux, or Credential Manager on Windows.

## Update the CLI

Update to the latest stable release:

```sh
zorveus update
```

Install a specific version:

```sh
zorveus update --version v0.1.0
```

`zorveus update` detects your OS and architecture, verifies the SHA-256 checksum, and replaces the binary you invoked without requiring a Zorveus login. Saved logins, stored secrets, and project files are preserved. If a download or checksum check fails, your current binary stays intact. Use `--json --non-interactive` in scripts.

## Manual shell completion

On macOS and Linux, the installer sets up completion automatically:

| Shell | What the installer writes |
| :--- | :--- |
| **zsh** | `~/.local/share/zorveus/completions/zorveus.zsh` and a loader in `~/.zshrc` |
| **bash** | `~/.local/share/bash-completion/completions/zorveus` and a loader in `.bashrc` (requires `bash-completion`) |
| **fish** | `~/.config/fish/completions/zorveus.fish` (loaded automatically) |

To load zsh completion manually in your current shell:

```zsh
autoload -Uz compinit
compinit
source <(zorveus completion zsh)
```

For bash, fish, or PowerShell completion scripts, run `zorveus completion --help`.
