One manifest describes one Zorveus app. The default file is `zorveus.json`. Offline commands (`init`, `validate`, `clone`, `promote`) check local syntax and references without making network calls.

The [JSON Schema](https://docs.zorveus.com/cli/manifest-v1.schema.json) defines all version 1 fields, types, and enums. The CLI embeds this schema locally and never fetches a remote `$schema` URL (that field is for editor autocomplete only).

---

## Root fields and resource identity

| Root field | Required | Purpose |
| :--- | :--- | :--- |
| `version` | Yes | Must be `1`. |
| `organizationId` | No | Organization that owns the app. Recorded automatically by `setup`, `import`, and `apply`. Used by `plan`, `status`, and `retrieve` to pick the matching saved login. Must match `--org` when both are supplied. |
| `_state` | No | Optional durable state backend configuration (`backend: "s3"`, `bucket`, `key`, optional `region`, `endpoint`, `usePathStyle`). See [Durable state and destroy](/cli/state-and-destroy). |
| `app` | Yes | App settings, models, credit conversion, OAuth, and consent defaults. |
| `keys` | No | Programmatic API keys keyed by stable local name (for example, `keys.backend`). |
| `routingKeys` | No | Routing keys keyed by stable local name (for example, `routingKeys.primary`). |
| `serviceKeys` | No | Organization service keys keyed by local name. |
| `providerCredentials` | No | Organization BYOK provider credentials keyed by local name. |

Resource object keys use 1 to 64 lowercase letters, digits, underscores, or hyphens (`keys.backend`, `routingKeys.primary`). The object key identifies the entry locally and across environments; `id` identifies the backend resource; `name` is the editable display name. Display names never identify resources.

IDs are 1 to 128 ASCII letters, digits, underscores, or hyphens starting with a letter or digit. Omitting `id` requests creation; explicit `null` or empty `id` is invalid.

| Input | Update behavior |
| :--- | :--- |
| Omitted resource section | Preserves previously managed resources in that section. |
| Explicit resource object | Reconciles its entries with the previously managed set while leaving unrelated resources untouched. |
| Explicit empty object (`{}`) | Proposes removing previously managed resources in that section (shared org credentials are not revoked). |
| Omitted optional field | Preserves the remote value (except `keys.<name>.allowedModels`, which inherits `app.allowedModels`). |
| Explicit `null` | Clears the field where the schema allows `null`. |

Nullable fields: `app.creditUnitsPerUsd`, key `cap` and `productUserChargeMultiplier`, routing `defaultSelector`, consent `defaultCap`, `minimumCapAmount`, `maximumCapAmount`, existing service-key `name`, and provider `providerConfig`.

## App fields

| Field | Type | Meaning |
| :--- | :--- | :--- |
| `id` | String | Existing app ID; omit to create an app. |
| `name` | String | Display name; required on creation. |
| `allowedModels` | String array | Model allowlist (`["*"]`, `["openai/*"]`, or exact model IDs); required on creation. |
| `allowedScopes` | String array | Allowed OAuth scopes; set on creation and checked for equality on existing apps. |
| `creditUnitsPerUsd` | Decimal string or `null` | Credit conversion rate; `null` clears it. |
| `productUserChargeMultiplier` | Decimal string | Default customer charge multiplier, at least `"1"`. |
| `oauth.clientType` | `public` or `confidential` | OAuth client type; set on creation and checked for equality on existing apps. |
| `oauth.redirectUris` | String array | Exact HTTP (`localhost`) or HTTPS callback URLs. |
| `consent.defaultCap` | Cap object or `null` | Default OAuth consent cap; `null` clears it. |
| `consent.minimumCapAmount` | Decimal string or `null` | Minimum consent cap amount. |
| `consent.maximumCapAmount` | Decimal string or `null` | Maximum consent cap amount. |
| `consent.allowUnlimitedCap` | Boolean | Whether OAuth users can pick an unlimited cap. |

The app update API cannot change `oauth.clientType` or `allowedScopes` on an existing app. Planning fails if you change either on an existing app.

## API key fields (`keys`)

Each entry under `keys` manages one programmatic API key policy. Its `id` is the underlying connection ID, which stays stable across key rotation.

| Field | Type | Meaning |
| :--- | :--- | :--- |
| `id` | String | Existing backend ID; omit to create. |
| `name` | String | Display name; required on creation. |
| `allowedModels` | String array | Optional subset of `app.allowedModels`; omitting inherits the app list. |
| `creditMode` | String | `disabled`, `track_only`, `enforce_if_present` (default), or `enforce`. |
| `overrunPolicy` | String | `limit_output` (default), `allow_overrun`, or `carry_overrun_forward`. |
| `productUserChargeMultiplier` | Decimal string or `null` | Per-key multiplier override; `null` removes the override. |
| `cap` | Cap object or `null` | Spending cap (`amount`, `currency`, `period`); `null` removes the cap. |

## Routing key fields (`routingKeys`)

| Field | Type | Meaning |
| :--- | :--- | :--- |
| `id` | String | Existing routing key ID (`api_key_id`). |
| `name` | String | Display name; required on creation. |
| `members` | String array | Object names from `keys` (up to 100); required on creation. |
| `defaultSelector` | String or `null` | Default member when no alias is sent; `null` clears it. |

The object key of each entry under `keys` (for example, `keys.pro`) becomes its routing selector (`pro`). Renaming a routing key's display `name` preserves its ID, secret, and memberships.

## Shared organization credentials

| Section | Field | Meaning |
| :--- | :--- | :--- |
| `serviceKeys` | `id` | Existing organization service-key ID. |
| `serviceKeys` | `name` | Display name; required on creation; existing names can be cleared with `null`. |
| `serviceKeys` | `scopes` | Runtime permissions (`product_users:read`, `product_users:write`); required on creation. |
| `providerCredentials` | `id` | Existing organization provider-credential ID. |
| `providerCredentials` | `name` | Display name; required on creation. |
| `providerCredentials` | `provider` | `openai`, `anthropic`, `gemini`, `azure`, `vertex_ai`, `nvidia_nim`, or `typesafe`; required on creation. |
| `providerCredentials` | `secretFromEnv` | Environment variable name holding the secret (never a literal key); required on creation. |
| `providerCredentials` | `secretKind` | `api_key`, `service_account_json`, or `azure_ad_token`; requires `secretFromEnv`. |
| `providerCredentials` | `providerConfig` | Nonsecret config object (`api_base`, `api_version`, `base_url`, `project`, `location`) or `null`. |
| `providerCredentials` | `routingMode` | `auto_resolve` (default), `manual_grant_only`, or `disabled`. |
| `providerCredentials` | `defaultModelPolicy` | Allowed model patterns for the credential. |

Azure credentials require `api_base` and `api_version` in `providerConfig`; Vertex AI requires `project` and `location`. `secretFromEnv` is resolved at `plan`/`apply` time from your shell environment (the CLI never loads `.env` files automatically) and fingerprinted locally in your OS credential store.

`clone` removes `organizationId`, `_state`, and app-owned IDs, and rejects manifests with nonempty `serviceKeys` or `providerCredentials` because those resources are shared across the organization.

## Decimal strings, caps, and validation limits

Amounts, conversion rates, and multipliers must be plain decimal strings (`"1.25"`, never `1.25` or `"1e2"`):

| Field | Bounds |
| :--- | :--- |
| Cap amounts, consent min/max, `creditUnitsPerUsd` | Greater than `0`, up to 12 whole digits and 12 fractional digits. |
| `productUserChargeMultiplier` | At least `1`, up to 12 whole digits and 6 fractional digits. |

A cap object has `amount`, a 3-letter uppercase `currency` (for example, `"USD"`), and `period` (`daily`, `monthly`, or `lifetime`).

Invalid manifests exit with code `2` and return `{ code, message, pointer }` (JSON Pointer location) without printing secret values. Unknown fields and duplicate keys are rejected. Files must be valid UTF-8, contain one JSON object, stay under 4 MiB, and stay within 64 nesting levels.
