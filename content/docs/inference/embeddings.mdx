Turn text into numbers you can use to find similar content. Vector databases use these embeddings to power semantic search, recommendations, and retrieval-augmented generation (RAG).

<ApiEndpoint method="POST" path="/v1/embeddings" auth="api_key" />

## Code examples

<CodeGroup titles={["TypeScript (OpenAI SDK)", "Python (OpenAI SDK)", "cURL"]}>

```typescript
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://api.zorveus.com/v1",
  apiKey: "zrv_your_api_key",
});

const response = await client.embeddings.create({
  model: "openai/text-embedding-3-small",
  input: "Vector databases index embeddings for approximate nearest neighbor search.",
});

console.log(`Generated embedding vector with ${response.data[0].embedding.length} dimensions.`);
```

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.zorveus.com/v1",
    api_key="zrv_your_api_key",
)

response = client.embeddings.create(
    model="openai/text-embedding-3-small",
    input="Vector databases index embeddings for approximate nearest neighbor search.",
)

vector = response.data[0].embedding
print(f"Generated embedding vector with {len(vector)} dimensions.")
```

## Request parameters

<ParamField name="model" type="string" required>
  The embedding model identifier, such as `openai/text-embedding-3-small` or `openai/text-embedding-3-large`.
</ParamField>

<ParamField name="input" type="string or array" required>
  A single text string or an array of strings to embed in a batch.
</ParamField>

<ParamField name="dimensions" type="integer">
  Optional target dimension count for models supporting variable vector sizes.
</ParamField>

<ParamField name="encoding_format" type="string" default="float">
  Format to return embeddings in: `float` (default array of numbers) or `base64`.
</ParamField>

## Response format

```json
{
  "object": "list",
  "data": [
    {
      "object": "embedding",
      "index": 0,
      "embedding": [
        -0.0069292834,
        -0.005336422,
        -0.024047505,
        0.008432145
      ]
    }
  ],
  "model": "openai/text-embedding-3-small",
  "usage": {
    "prompt_tokens": 10,
    "total_tokens": 10
  }
}
```

<ResponseField name="data" type="array" required>
  Array of embedding objects. Each object contains an `index` and the numerical `embedding` float array.
</ResponseField>

<ResponseField name="usage.total_tokens" type="integer" required>
  The billable token count for the input text.
</ResponseField>

## Customer spending limits

If you generate embeddings on behalf of individual customers (such as private document search or RAG indexing), attach their customer ID:

```http
X-Zorveus-External-User-ID: customer_42
```

If you fetch customer activity lists or show usage history in your product, attach an optional activity label:

```http
X-Zorveus-Usage-Metadata: {"activity_label": "Document indexing"}
```

`X-Zorveus-Usage-Metadata` accepts any custom JSON object up to 4 KB. When your backend fetches your customer's usage list through [Product-user activity](/startups/product-user-activity), Zorveus returns these saved fields with each request item.

In the Zorveus SDK:

```typescript
const response = await client.embeddings.create(
  {
    model: "openai/text-embedding-3-small",
    input: "Document text to index",
  },
  {
    headers: {
      "X-Zorveus-External-User-ID": "customer_42",
      "X-Zorveus-Usage-Metadata": JSON.stringify({ activity_label: "Document indexing" }),
    },
  }
);
```

Token costs are settled against `customer_42`'s active allowance. Follow [Add customer usage limits](/getting-started/product-user-quickstart) to set up per-user spending caps.
