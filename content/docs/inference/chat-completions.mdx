<ApiEndpoint method="POST" path="/v1/chat/completions" auth="api_key" />

The `/v1/chat/completions` endpoint generates text, code, or structured reasoning responses from AI models

<KeyInserter type="api" label="API Key Tester" placeholder="zrv_your_api_key" />

---

## Authentication

Requests authenticate using an API Key in the `Authorization` header:

```http
Authorization: Bearer zrv_your_api_key
```

---

## Request parameters

<ParamField name="model" type="string" required>
  The model identifier to route the request to (e.g. `openai/gpt-6-sol`, `anthropic/claude-sonnet-5`, `gemini/gemini-3.8-flash`)
</ParamField>

<ParamField name="messages" type="array" required>
  An array of message objects representing the conversation history. Each object contains `role` (`system`, `user`, `assistant`, `tool`) and `content`
</ParamField>

<ParamField name="temperature" type="number">
  Optional sampling setting. Supported values and defaults depend on the model. Some reasoning models reject this field
</ParamField>

<ParamField name="max_tokens" type="integer">
  Output token limit for models that accept it. Some reasoning models use `max_completion_tokens` instead. See the chosen model's parameter contract
</ParamField>

<ParamField name="stream" type="boolean" default="false">
  If `true`, tokens are returned via Server-Sent Events (SSE)
</ParamField>

<ParamField name="metadata" type="object">
  Zorveus attribution metadata. Use `external_user_id` for your customer ID and put optional profile fields inside `product_user`
</ParamField>

## Code examples

<CodeGroup titles={["Python (OpenAI SDK)", "TypeScript (OpenAI SDK)", "cURL"]}>

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.zorveus.com/v1",
    api_key="zrv_your_api_key",
)

response = client.chat.completions.create(
    model="openai/gpt-6-sol",
    messages=[
        {"role": "system", "content": "You are a senior systems engineer."},
        {"role": "user", "content": "Explain write-ahead logging (WAL) concisely."},
    ],
    extra_body={
        "metadata": {
            "external_user_id": "usr_dev_4812",
        }
    },
)

print(response.choices[0].message.content)
```

```typescript
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://api.zorveus.com/v1",
  apiKey: "zrv_your_api_key",
});

async function main() {
  const completion = await client.chat.completions.create({
    model: "openai/gpt-6-sol",
    messages: [
      { role: "system", content: "You are a senior systems engineer." },
      { role: "user", content: "Explain write-ahead logging (WAL) concisely." },
    ],
    metadata: { external_user_id: "usr_dev_4812" },
  });

  console.log(completion.choices[0].message.content);
}

main();
```

## Common errors

| Error Code | HTTP Status | Root Cause & Resolution |
| :--- | :--- | :--- |
| `zorveus_malformed_or_missing_key` | 401 | The API key is missing, invalid, or revoked. Check key configuration. |
| `zorveus_reservation_insufficient_balance` | 402 | Organization wallet lacks funds to cover the estimated wallet charge or BYOK platform fee. Top up wallet balance. |
| `zorveus_product_user_allowance_insufficient` | 403 | The estimated request cost exceeds the product user's remaining base allowance plus promotional credits. |
| `zorveus_cap_exceeded` | 403 | The organization, connection, or product-user spending cap has been reached. |
| `zorveus_model_not_allowed` | 403 | The requested model is outside your connection's allowed model policy. |
| `rate_limit_exceeded` | 429 | Upstream model provider rate limit reached. Retry with exponential backoff. |
