Send product-user metadata with an OpenAI-compatible request to attribute usage and apply product-user controls.

<KeyInserter type="inference" label="Inference Key Tester" placeholder="zrv_your_inference_key" />

---

## Supported metadata fields

The request `metadata` object accepts these fields. In the Python OpenAI client, put the object at `extra_body.metadata`.

| Field | Type | Description |
| :--- | :--- | :--- |
| `external_user_id` | string | Stable customer ID from your application. |
| `product_end_user_id` | string | Internal Zorveus product-user ID. |
| `product_user.display_name` | string | Name shown in the dashboard. |
| `product_user.email` | string | Email used to derive the stored email hash. |
| `product_user.metadata` | object | Your custom fields, such as `plan` or `workspace_id`. |

---

## Send metadata

<CodeGroup titles={["Python (OpenAI SDK)", "TypeScript (OpenAI SDK)"]}>

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.zorveus.com/v1",
    api_key="zrv_your_inference_key",
)

response = client.chat.completions.create(
    model="openai/gpt-4.1-mini",
    messages=[{"role": "user", "content": "Generate 3 taglines for an electric bicycle."}],
    extra_body={
        "metadata": {
            "external_user_id": "cust_uuid_9921",
            "product_user": {
                "display_name": "Alex Mercer",
                "email": "alex.mercer@company.io",
                "metadata": {"plan": "pro_tier"},
            },
        }
    },
)

print(response.choices[0].message.content)
```

```typescript
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://api.zorveus.com/v1",
  apiKey: "zrv_your_inference_key",
});

async function main() {
  const completion = await client.chat.completions.create({
    model: "openai/gpt-4.1-mini",
    messages: [{ role: "user", content: "Generate 3 taglines for an electric bicycle." }],
    ...({
      metadata: {
        external_user_id: "cust_uuid_9921",
        product_user: {
          display_name: "Alex Mercer",
          email: "alex.mercer@company.io",
          metadata: { plan: "pro_tier" },
        },
      },
    } as any),
  });

  console.log(completion.choices[0].message.content);
}

main();
```

</CodeGroup>

If you provide both IDs, `product_end_user_id` identifies the existing Zorveus record. `external_user_id` remains your application-facing lookup key. The gateway does not infer `external_user_id` from the OpenAI `user` field.
