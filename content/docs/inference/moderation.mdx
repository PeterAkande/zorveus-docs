Screen text inputs against safety policies using moderation endpoints.

<ApiEndpoint method="POST" path="/v1/moderations" auth="api_key" />

## Code example

<CodeGroup titles={["Python (OpenAI SDK)", "TypeScript (OpenAI SDK)", "cURL"]}>

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.zorveus.com/v1",
    api_key="zrv_your_api_key",
)

response = client.moderations.create(
    model="openai/omni-moderation-latest",
    input="Sample text content for automated compliance screening.",
)

result = response.results[0]
print(f"Flagged: {result.flagged}")
print(f"Categories: {result.categories}")
```

```typescript
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://api.zorveus.com/v1",
  apiKey: "zrv_your_api_key",
});

async function main() {
  const response = await client.moderations.create({
    model: "openai/omni-moderation-latest",
    input: "Sample text content for automated compliance screening.",
  });

  console.log(response.results[0]);
}

main();
```

```bash
curl https://api.zorveus.com/v1/moderations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer zrv_your_api_key" \
  -d '{
    "model": "openai/omni-moderation-latest",
    "input": "Sample text content for automated compliance screening."
  }'
```

</CodeGroup>

## Read the result

Read `results[0].flagged` for the provider's overall safety decision, and inspect category fields when your policy needs them. Category names and scores vary between moderation models, so store the model ID with any audit decision.
