## Code examples

<CodeGroup titles={["TypeScript (OpenAI SDK)", "Python (OpenAI SDK)", "cURL"]}>

```typescript
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://api.zorveus.com/v1",
  apiKey: "zrv_your_api_key",
});

const response = await client.images.generate({
  model: "openai/dall-e-3",
  prompt: "A modern minimalist geometric workspace with emerald mint lighting",
  size: "1024x1024",
  response_format: "url",
  n: 1,
});

console.log("Image URL:", response.data?.[0]?.url);
```

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.zorveus.com/v1",
    api_key="zrv_your_api_key",
)

response = client.images.generate(
    model="openai/dall-e-3",
    prompt="A modern minimalist geometric workspace with emerald mint lighting",
    size="1024x1024",
    response_format="url",
    n=1,
)

print("Image URL:", response.data[0].url)
```

## Request parameters

<ParamField name="prompt" type="string" required>
  A text description of the desired image. Maximum length depends on the model.
</ParamField>

<ParamField name="model" type="string" default="openai/dall-e-3">
  The image generation model to use. Verify allowed models in your connection policy.
</ParamField>

<ParamField name="size" type="string" default="1024x1024">
  Output dimensions: `1024x1024`, `1024x1792`, or `1792x1024`.
</ParamField>

<ParamField name="response_format" type="string" default="url">
  `url` to receive a temporary download link, or `b64_json` to receive raw base64-encoded image data.
</ParamField>

<ParamField name="quality" type="string" default="standard">
  `standard` or `hd` for models supporting high definition.
</ParamField>

## Response format

```json
{
  "created": 1715000000,
  "data": [
    {
      "url": "https://oaidalleapiprodscus.blob.core.windows.net/private/image.png",
      "revised_prompt": "A modern minimalist geometric workspace with emerald mint lighting..."
    }
  ]
}
```

<ResponseField name="data" type="array" required>
  Array of generated image objects containing `url` or `b64_json`.
</ResponseField>
