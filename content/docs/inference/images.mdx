## Code example

<CodeGroup titles={["Python (OpenAI SDK)", "TypeScript (OpenAI SDK)"]}>

```python
import os
from openai import OpenAI

client = OpenAI(
    base_url="https://api.zorveus.com/v1",
    api_key="zrv_your_api_key",
)

response = client.images.generate(
    model=os.environ["ZORVEUS_IMAGE_MODEL"],
    prompt="A modern minimalist geometric workspace with emerald mint lighting",
    size="1024x1024",
    response_format="b64_json",
    n=1,
)

print("Received image:", bool(response.data and response.data[0].b64_json))
```

```typescript
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://api.zorveus.com/v1",
  apiKey: "zrv_your_api_key",
});

async function main() {
  const image = await client.images.generate({
    model: process.env.ZORVEUS_IMAGE_MODEL!,
    prompt: "A modern minimalist geometric workspace with emerald mint lighting",
    size: "1024x1024",
    response_format: "b64_json",
    n: 1,
  });

  console.log("Received image:", Boolean(image.data?.[0]?.b64_json));
}

main();
```

## Handle image data

Providers can return a temporary URL, base64 data, or another provider-specific result. Decode `b64_json` to save an image when the selected model supports that response format

Check `GET /v1/models` before using the example model. Image size, quality, count, response format, and content-policy behavior depend on the selected model

Do not log base64 image output or place provider URLs in long-lived records unless your data policy permits it

Set `ZORVEUS_IMAGE_MODEL` to a returned model ID that supports image generation. Supported sizes and response-format options depend on that model
