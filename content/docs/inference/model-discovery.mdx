Browse all supported models in the [Zorveus model catalog](https://www.zorveus.com/models), or query the `/v1/models` endpoint from your app to see which models your API key is authorized to route.

<ApiEndpoint method="GET" path="/v1/models" auth="api_key" />

## List available models

Send a `GET` request to `/v1/models` using the OpenAI SDK or cURL.

<CodeGroup titles={["TypeScript (@zorveus/sdk)", "Python (zorveus)", "TypeScript (OpenAI SDK)", "Python (OpenAI SDK)", "cURL"]}>

```typescript
import { Zorveus } from "@zorveus/sdk";

const client = new Zorveus({
  apiKey: "zrv_your_api_key",
});

const models = await client.models.list();
for (const model of models.data) {
  console.log(`${model.id} (Owner: ${model.owned_by})`);
}
```

```python
from zorveus import Zorveus

client = Zorveus(api_key="zrv_your_api_key")

models = client.models.list()
for model in models.data:
    print(f"{model.id} (Owner: {model.owned_by})")
```

```typescript
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://api.zorveus.com/v1",
  apiKey: "zrv_your_api_key",
});

const models = await client.models.list();
for (const model of models.data) {
  console.log(`${model.id} (Owner: ${model.owned_by})`);
}
```

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.zorveus.com/v1",

```

## Policy expansion

When your app connection defines wildcard policies like `*` or `openai/*`, the `/v1/models` endpoint expands those wildcards into concrete routable model IDs, such as `openai/gpt-4.1-mini`, `anthropic/claude-sonnet-5`, and `gemini/gemini-2.5-flash`.

Wildcard strings are policy configurations. They are not valid model identifiers in inference requests. Use the exact `id` strings returned by this endpoint.

## Read the response

A successful response has `object: "list"` and a `data` array:

```json
{
  "object": "list",
  "data": [
    {
      "id": "openai/gpt-4.1-mini",
      "object": "model",
      "created": 1715000000,
      "owned_by": "openai"
    },
    {
      "id": "anthropic/claude-sonnet-5",
      "object": "model",
      "created": 1715000000,
      "owned_by": "anthropic"
    }
  ]
}
```

With a routing key, send `X-Zorveus-Key-Alias` to discover the chosen member's allowed models. If no alias is sent, a configured default member is required.

To check pricing, context limits, and capabilities across all 850+ models, browse the [Zorveus model catalog](https://www.zorveus.com/models) or the [Models API reference](/api-reference/models). A key-scoped list from `/v1/models` checks access for your specific credentials.
