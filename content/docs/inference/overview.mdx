Use Zorveus to call AI models from your app. Choose a model, send a request, and use the response. You can generate text, stream replies, create images, and work with audio.

Send requests to over 850 models across OpenAI, Anthropic, Google Gemini, and Jev through one endpoint. Browse the full list in the [model catalog](https://www.zorveus.com/models). Keep using your existing OpenAI or Anthropic SDKs by pointing the base URL to Zorveus.

## Make a request

Point your client to Zorveus and pass your API key.

<CodeGroup titles={["Anthropic (Python)", "Anthropic (TypeScript)", "OpenAI (Python)", "OpenAI (TypeScript)", "cURL"]}>

```python
import anthropic

client = anthropic.Anthropic(
    base_url="https://api.zorveus.com",
    api_key="zrv_your_api_key",
)

response = client.messages.create(
    model="anthropic/claude-sonnet-5",
    max_tokens=1024,
    messages=[
        {"role": "user", "content": "Explain quantum computing in one sentence."}
    ],
)
print(response.content[0].text)
```

```typescript
import Anthropic from "@anthropic-ai/sdk";

const anthropic = new Anthropic({
  baseURL: "https://api.zorveus.com",
  apiKey: "zrv_your_api_key",
});

const message = await anthropic.messages.create({
  model: "anthropic/claude-sonnet-5",
  max_tokens: 1024,
  messages: [{ role: "user", content: "Explain quantum computing in one sentence." }],
});

console.log(message.content[0].text);
```

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.zorveus.com/v1",
    api_key="zrv_your_api_key",
)

response = client.chat.completions.create(
    model="openai/gpt-4.1-mini",
    messages=[{"role": "user", "content": "Explain quantum computing in one sentence."}],
)
print(response.choices[0].message.content)
```

```typescript
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://api.zorveus.com/v1",
  apiKey: "zrv_your_api_key",
});

const completion = await client.chat.completions.create({
  model: "openai/gpt-4.1-mini",
  messages: [{ role: "user", content: "Explain quantum computing in one sentence." }],
});

console.log(completion.choices[0].message.content);
```

```bash
curl https://api.zorveus.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer zrv_your_api_key" \
  -d '{
    "model": "openai/gpt-4.1-mini",
    "messages": [{"role": "user", "content": "Explain quantum computing in one sentence."}]
  }'
```

## Base URL rules

Different SDK clients append different default path prefixes. Configure the base URL matching your client:

| Client | Base URL | What the SDK appends |
| :--- | :--- | :--- |
| **OpenAI Python / TypeScript** | `https://api.zorveus.com/v1` | Automatically appends `/chat/completions`. |
| **Anthropic Python / TypeScript** | `https://api.zorveus.com` | Automatically appends `/v1/messages`. Do not add `/v1`. |
| **Google Gemini native wire protocol** | `https://api.zorveus.com` | Supports `POST /v1beta/models/*` and `POST /vertex_ai/live` in addition to `/v1/chat/completions`. |
| **Zorveus SDK (@zorveus/sdk)** | Preconfigured | Connects to `https://api.zorveus.com`. |
| **Direct HTTP / cURL** | Full endpoint URL | Use `https://api.zorveus.com/v1/chat/completions` or `https://api.zorveus.com/v1/messages`. |

<Callout type="warning" title="Avoid Anthropic base URL 404 errors">
  Do not append `/v1` to the base URL when using the official Anthropic SDK (`@anthropic-ai/sdk` or `anthropic-python`). The Anthropic client appends `/v1/messages` on its own. Setting `baseURL: "https://api.zorveus.com/v1"` results in an invalid `https://api.zorveus.com/v1/v1/messages` request.
</Callout>
