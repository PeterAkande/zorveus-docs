## Generate speech (Text-to-speech)

<ApiEndpoint method="POST" path="/v1/audio/speech" auth="api_key" />

Synthesizes spoken audio from text input in formats like MP3, AAC, or Opus.

<CodeGroup titles={["TypeScript (OpenAI SDK)", "Python (OpenAI SDK)", "cURL"]}>

```typescript
import OpenAI from "openai";
import fs from "fs";

const client = new OpenAI({
  baseURL: "https://api.zorveus.com/v1",
  apiKey: "zrv_your_api_key",
});

const mp3 = await client.audio.speech.create({
  model: "openai/tts-1",
  voice: "alloy",
  input: "Welcome to Zorveus. Your unified AI billing and gateway platform.",
});

const buffer = Buffer.from(await mp3.arrayBuffer());
await fs.promises.writeFile("welcome.mp3", buffer);
console.log("Saved audio to welcome.mp3");
```

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.zorveus.com/v1",
    api_key="zrv_your_api_key",
)

response = client.audio.speech.create(
    model="openai/tts-1",
    voice="alloy",
    input="Welcome to Zorveus. Your unified AI billing and gateway platform.",
)

response.stream_to_file("welcome.mp3")
print("Saved audio to welcome.mp3")
```

```bash
curl https://api.zorveus.com/v1/audio/speech \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer zrv_your_api_key" \
  --output welcome.mp3 \
  -d '{
    "model": "openai/tts-1",
    "voice": "alloy",
    "input": "Welcome to Zorveus. Your unified AI billing and gateway platform."
  }'
```

</CodeGroup>

### Request parameters

<ParamField name="model" type="string" required>
  The speech synthesis model ID, such as `openai/tts-1` or `openai/tts-1-hd`.
</ParamField>

<ParamField name="input" type="string" required>
  The text to speak. Maximum 4,096 characters per request.
</ParamField>

<ParamField name="voice" type="string" required>
  Voice profile: `alloy`, `echo`, `fable`, `onyx`, `nova`, or `shimmer`.
</ParamField>

<ParamField name="response_format" type="string" default="mp3">
  Audio format: `mp3`, `opus`, `aac`, `flac`, `wav`, or `pcm`.
</ParamField>

## Transcribe audio (Speech-to-text)

<ApiEndpoint method="POST" path="/v1/audio/transcriptions" auth="api_key" />

Transcribe recorded audio into text.

<CodeGroup titles={["TypeScript (OpenAI SDK)", "Python (OpenAI SDK)", "cURL"]}>

```typescript
import OpenAI from "openai";
import fs from "fs";

const client = new OpenAI({
  baseURL: "https://api.zorveus.com/v1",
  apiKey: "zrv_your_api_key",
});

const transcript = await client.audio.transcriptions.create({
  model: "openai/whisper-1",
  file: fs.createReadStream("meeting.wav"),
});

console.log("Transcript:", transcript.text);
```

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.zorveus.com/v1",
    api_key="zrv_your_api_key",
)

with open("meeting.wav", "rb") as audio_file:
    transcript = client.audio.transcriptions.create(
        model="openai/whisper-1",
        file=audio_file,
    )

print("Transcript:", transcript.text)
```

```bash
curl https://api.zorveus.com/v1/audio/transcriptions \
  -H "Authorization: Bearer zrv_your_api_key" \
  -F "file=@meeting.wav" \
  -F "model=openai/whisper-1"
```

## Customer spending limits

For text-to-speech and Whisper audio transcriptions, pass the customer ID in the request header:

```http
X-Zorveus-External-User-ID: customer_42
```

If you fetch customer activity lists or show usage history in your product, send an optional activity label:

```http
X-Zorveus-Usage-Metadata: {"activity_label": "Meeting transcription"}
```

`X-Zorveus-Usage-Metadata` accepts any custom JSON object up to 4 KB. When your backend fetches your customer's usage list through [Product-user activity](/startups/product-user-activity), Zorveus returns these saved fields with each request item.

Headers work across both JSON requests (`POST /v1/audio/speech`) and multipart audio uploads (`POST /v1/audio/transcriptions`), making them the recommended way to attribute audio generation and transcription jobs to specific customers. Follow [Add customer usage limits](/getting-started/product-user-quickstart) to configure per-user allowances.
