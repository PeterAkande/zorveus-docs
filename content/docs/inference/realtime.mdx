---
title: Realtime audio
description: Connect to realtime voice and audio models over WebSockets or short-lived client sessions.
---

Realtime models use a long-lived connection rather than a standard request-response cycle. Choose a model that supports realtime from [the model catalog](/api-reference/models), then verify it is available to your API key.

## Connect through the gateway

Gateway routes include `WS /v1/realtime` and `POST /v1/realtime/calls`. Keep your long-lived service or inference key on your server. Attach the customer's external user ID so the session can be attributed.

For a server-side WebSocket using Node.js:

```javascript
import WebSocket from "ws";

const url = new URL("wss://api.zorveus.com/v1/realtime");
url.searchParams.set("model", process.env.ZORVEUS_REALTIME_MODEL);

const socket = new WebSocket(url, {
  headers: {
    Authorization: `Bearer ${process.env.ZORVEUS_API_KEY}`,
    "X-Zorveus-External-User-ID": "customer_42",
  },
});

socket.on("message", (data) => {
  const event = JSON.parse(data.toString());
  console.log(event.type);
});

socket.on("error", (error) => console.error(error.message));
```

Set `ZORVEUS_REALTIME_MODEL` to a realtime model ID available to your key.

## Create a provider client secret

<ApiEndpoint method="POST" path="/v1/realtime/client_secrets" auth="api_key" />

Your backend can request a short-lived provider secret for a browser or mobile session. The setup request does not represent model usage or reserve future spend:

```python
import os
import requests

response = requests.post(
    "https://api.zorveus.com/v1/realtime/client_secrets",
    headers={"Authorization": f"Bearer {os.environ['ZORVEUS_API_KEY']}"},
    json={"session": {"type": "realtime", "model": os.environ["ZORVEUS_REALTIME_MODEL"]}},
    timeout=30,
)
```
