Use the Responses API if your application uses OpenAI's newer `client.responses.create` endpoint for unified text, tools, and multimodal generations.

<ApiEndpoint method="POST" path="/v1/responses" auth="api_key" />

<KeyInserter type="api" label="API Key" placeholder="zrv_your_api_key" />

## Code examples

<CodeGroup titles={["TypeScript (OpenAI SDK)", "Python (OpenAI SDK)", "cURL"]}>

```typescript
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://api.zorveus.com/v1",
  apiKey: "zrv_your_api_key",
});

const response = await client.responses.create({
  model: "openai/gpt-4.1-mini",
  input: "What are three core benefits of edge computing?",
});

console.log(response.output_text);
```

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.zorveus.com/v1",
    api_key="zrv_your_api_key",
)

response = client.responses.create(
    model="openai/gpt-4.1-mini",
    input="What are three core benefits of edge computing?",
)

print(response.output_text)
```

```bash
curl https://api.zorveus.com/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer zrv_your_api_key" \
  -d '{
    "model": "openai/gpt-4.1-mini",
    "input": "What are three core benefits of edge computing?"
  }'
```

## Response format

```json
{
  "id": "resp_01JABC123",
  "object": "response",
  "created": 1715000000,
  "model": "openai/gpt-4.1-mini",
  "output_text": "1. Lower Latency: Processing data closer to the source reduces transmission delays.\n2. Reduced Bandwidth: Less data must travel to central cloud servers.\n3. Enhanced Reliability: Local nodes continue functioning during network disruptions.",
  "usage": {
    "input_tokens": 16,
    "output_tokens": 48,
    "total_tokens": 64
  }
}
```

<ResponseField name="output_text" type="string" required>
  Convenience string containing the model's text output.
</ResponseField>

<ResponseField name="usage" type="object" required>
  Token consumption details settled against your wallet or allowance.
</ResponseField>
