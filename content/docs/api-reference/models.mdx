title: Models Catalog API
description: Routable model discovery

<ApiEndpoint method="GET" path="/models" auth="api_key" />
Use the API key to list models supported for that API key based on its model policies.
### Parameters

<ParamField name="provider" type="string">
  Filters or selects the request by provider.
</ParamField>

<ParamField name="route_status" type="string">
  Whether Zorveus can safely route and bill a model. Allowed values: `available`, `pricing_only`, `blocked`.
</ParamField>

<ParamField name="q" type="string">
  Filters or selects the request by q.
</ParamField>

<ParamField name="limit" type="integer">
  Filters or selects the request by limit.
</ParamField>

### Responses

#### 200 Successful Response

<ResponseField name="items" type="array<object>" required>
  Returns the items value.
</ResponseField>

#### 422 Validation Error

<ResponseField name="detail" type="array<object>">
  Returns the detail value.
</ResponseField>
