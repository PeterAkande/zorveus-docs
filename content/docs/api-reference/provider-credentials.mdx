---
title: Provider credentials
description: Set up BYOK credentials in the dashboard before making inference requests.
---

Manage provider credentials in the Zorveus dashboard under **Provider Credentials**. The SDK uses your Zorveus inference key after setup.

See [Provider keys (BYOK)](/startups/provider-credentials) for dashboard setup and supported providers, and [Key priority, rotation, and fallback](/startups/automatic-routing) for multi-key priority and wallet fallback.
