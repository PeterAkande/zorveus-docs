---
title: Provider credentials
description: Manage provider credentials in the dashboard, not through application API requests.
---

Manage provider credentials in the Zorveus dashboard under **Provider Credentials**. Application code does not call a provider-credential API. Use a Zorveus API key for inference, not the upstream provider secret.

See [Manage provider credentials](/startups/provider-credentials) for dashboard steps and [Provider integrations](/providers/overview) for provider-specific requirements.
