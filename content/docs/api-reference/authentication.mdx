---
title: Authentication
description: Authentication methods for the Zorveus API.
---

Every request to the Zorveus API must be authenticated. The API distinguishes between two distinct credential types:

1. **API Key (`zrv_...`)**: Used to execute LLM inference requests against `https://api.zorveus.com/v1` (and provider-native endpoints) or inspect connection spend on `/inference-keys/usage`. API keys are issued under an App Connection and enforce model access policies and spend caps.
2. **Service Key (`zrv_svc_...`)**: Used exclusively for backend organization management against `https://api.zorveus.com`. Service keys manage apps, provider credentials, product users, and webhooks. They cannot make inference requests.
