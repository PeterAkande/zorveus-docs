---
title: Auth
description: Authentication methods for the Zorveus API.
---

Every request to the Zorveus API must be authenticated. The API supports two authentication methods:
1. **Service Key**: A service key is a long-lived API key that can be used to authenticate requests to the Zorveus API. Service keys are associated with an organization and can be used to perform operations on behalf of the organization.
2. **Inference Key**: An inference key is the API Key used for LLM inference requests.
