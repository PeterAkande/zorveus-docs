Use these endpoints to manage customer allowances, read usage profiles, and grant promotional or purchased credits from your backend.

All routes require a server-side service key (`Bearer zrv_svc_...`) sent from your backend. Never expose service keys to browser clients. Identify each customer by supplying your `app_id` and stable `external_user_id`.

<KeyInserter type="service" label="Service Key" placeholder="zrv_svc_your_service_key" />

| Operation | Method and path | Scope |
| --- | --- | --- |
| [Read profile and allowance](#get-product-user-by-external-id) | `GET /product-users/by-external-id` | `product_users:read` |
| [Create or update profile](#upsert-product-user-by-external-id) | `PUT /product-users/by-external-id` | `product_users:write` |
| [Read credit balance](#get-credit-summary) | `GET /product-users/by-external-id/credit-summary` | `product_users:read` |
| [Read carried allowance debt](#get-allowance-debt) | `GET /product-users/by-external-id/allowance-debt` | `product_users:read` |
| [Grant credits](#grant-credits) | `POST /product-users/by-external-id/credit-grants` | `product_users:write` |
| [List grants](#list-credit-grants) | `GET /product-users/by-external-id/credit-grants` | `product_users:read` |
| [Find grant by reference](#find-a-credit-grant-by-reference) | `GET /product-users/by-external-id/credit-grants/by-reference` | `product_users:read` |

## Get product user by external ID

<ApiEndpoint method="GET" path="/product-users/by-external-id" auth="service_key" />

Look up a customer's usage, active cap, and effective remaining allowance. 

By default, this endpoint returns `404` if the customer has not made a request yet. To automatically create the profile if it does not exist, include the `X-Zorveus-Upsert-Product-User: true` header.

<CodeGroup titles={["cURL", "Python", "TypeScript"]}>

```bash
curl --fail-with-body --get https://api.zorveus.com/product-users/by-external-id \
	-H "Authorization: Bearer zrv_svc_your_service_key" \
	-H "X-Zorveus-Upsert-Product-User: true" \
	--data-urlencode "app_id=app_123" \
	--data-urlencode "external_user_id=customer_42"
```

```python
from zorveus import ZorveusServiceClient

service = ZorveusServiceClient(api_key="zrv_svc_your_service_key")

user = service.product_users.get_by_external_id(
    app_id="app_123",
    external_user_id="customer_42",
    upsert_if_missing=True,
)

print(f"User: {user.external_user_id}")
if user.allowance:
    print(f"Available allowance: ${user.allowance.available_allowance}")
```

```typescript
import { ZorveusServiceClient } from "@zorveus/sdk";

const service = new ZorveusServiceClient({ apiKey: "zrv_svc_your_service_key" });

const user = await service.productUsers.getByExternalId({
  appId: "app_123",
  externalUserId: "customer_42",
  upsertIfMissing: true,
});

console.log(`User: ${user.external_user_id}`);
if (user.allowance) {
  console.log(`Available allowance: $${user.allowance.available_allowance}`);
}
```

</CodeGroup>

</ParamField>

</ParamField>

## Upsert product user by external ID

<ApiEndpoint method="PUT" path="/product-users/by-external-id" auth="service_key" />

Create or update a customer profile, display name, email, metadata, or billing anchor date.

<CodeGroup titles={["cURL", "Python", "TypeScript"]}>

```bash
curl --fail-with-body --request PUT https://api.zorveus.com/product-users/by-external-id \
	-H "Authorization: Bearer zrv_svc_your_service_key" \
	-H "Content-Type: application/json" \
	-d '{
		"app_id": "app_123",
		"external_user_id": "customer_42",
		"display_name": "Acme Corp",
		"metadata": { "tier": "enterprise" }
	}'
```

```python
from zorveus import ZorveusServiceClient

service = ZorveusServiceClient(api_key="zrv_svc_your_service_key")

result = service.product_users.create_or_update(
    app_id="app_123",
    external_user_id="customer_42",
    display_name="Acme Corp",
    metadata={"tier": "enterprise"},
)

print(f"Created new user: {result.created}")
```

```typescript
import { ZorveusServiceClient } from "@zorveus/sdk";

const service = new ZorveusServiceClient({ apiKey: "zrv_svc_your_service_key" });

const result = await service.productUsers.createOrUpdate({
  appId: "app_123",
  externalUserId: "customer_42",
  displayName: "Acme Corp",
  metadata: { tier: "enterprise" },
});

console.log(`Created new user: ${result.created}`);
```

</CodeGroup>

### Request body

<ParamField name="app_id" type="string" required>
  Your Zorveus application ID.

<ParamField name="external_user_id" type="string" required>

## Grant credits

<ApiEndpoint method="POST" path="/product-users/by-external-id/credit-grants" auth="service_key" />

Grant one-time credits to a customer following a top-up purchase, plan upgrade, or promotional event.

Including an `external_reference` guarantees idempotency. If a network retry occurs with the same reference, Zorveus safely returns the existing grant without creating a duplicate charge.

<CodeGroup titles={["cURL", "Python", "TypeScript"]}>

```bash
curl --fail-with-body https://api.zorveus.com/product-users/by-external-id/credit-grants \
	-H "Authorization: Bearer zrv_svc_your_service_key" \
	-H "Content-Type: application/json" \
	-d '{
		"app_id": "app_123",
		"external_user_id": "customer_42",
		"amount": "10.00",
		"currency": "USD",
		"source": "purchase",
		"external_reference": "stripe_pi_3N4v9B2eZvKYlo2C01234567",
		"reason": "100k token pack purchase"
	}'
```

```python
receipt = service.product_users.grant_credit_by_external_id(
    app_id="app_123",
    external_user_id="customer_42",
    amount="10.00",
    external_reference="stripe_pi_3N4v9B2eZvKYlo2C01234567",
    source="purchase",
    reason="100k token pack purchase",
)

print(f"Granted: ${receipt.credit_grant.amount}")
print(f"New balance: ${receipt.credit_summary.available_credits}")
```

```typescript
const receipt = await service.productUsers.grantCreditByExternalId({
  appId: "app_123",
  externalUserId: "customer_42",
  amount: "10.00",
  externalReference: "stripe_pi_3N4v9B2eZvKYlo2C01234567",
  source: "purchase",
  reason: "100k token pack purchase",
});

console.log(`Granted: $${receipt.credit_grant.amount}`);
console.log(`New balance: $${receipt.credit_summary.available_credits}`);
```

</CodeGroup>

### Request body

<ParamField name="app_id" type="string" required>

</ParamField>

<ParamField name="amount" type="string" required>
  Grant value as a positive decimal string, such as `"10.00"`.
</ParamField>

</ParamField>

<ParamField name="reason" type="string">
  Human-readable description displayed in dashboard audit logs.
</ParamField>

<ParamField name="expires_at" type="string">
  ISO 8601 expiration timestamp, or omit for credits that never expire.
</ParamField>

## Error handling

| HTTP status | Error code | Reason |
| --- | --- | --- |
| `400` | `zorveus_invalid_external_user_id` | Missing or malformed external user ID. |
| `401` | `zorveus_unknown_service_key` | Service key is missing or invalid. |
| `403` | `zorveus_service_key_scope_required` | Service key does not have `product_users:read` or `product_users:write` scope. |
| `404` | `zorveus_product_user_not_found` | Customer does not exist in this app. Pass `X-Zorveus-Upsert-Product-User: true` to auto-create. |
| `409` | `zorveus_product_user_credit_reference_conflict` | A grant with the same `external_reference` exists with different parameters. |
