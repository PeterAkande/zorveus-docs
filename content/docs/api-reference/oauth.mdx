Zorveus OAuth 2.0 with S256 PKCE lets users connect their Zorveus account to your app and pay for their own AI model requests.

<KeyInserter type="client" label="Client ID" placeholder="zrv_client_your_client_id" />

| Operation | Method and URL | Request type |
| :--- | :--- | :--- |
| [Authorize user](#authorize-user) | `GET https://app.zorveus.com/oauth/authorize` | Browser redirect with PKCE |
| [Exchange code for token](#exchange-code-for-token) | `POST https://api.zorveus.com/oauth/token` | Form URL-encoded request |
| [Revoke token](#revoke-token) | `POST https://api.zorveus.com/oauth/revoke` | Form URL-encoded request |

## Authorize user

<ApiEndpoint method="GET" path="https://app.zorveus.com/oauth/authorize" />

Redirect the user's browser to the Zorveus consent screen.

```text
https://app.zorveus.com/oauth/authorize?response_type=code&client_id=zrv_client_your_client_id&redirect_uri=https%3A%2F%2Fmyapp.com%2Fcallback&scope=inference%3Awrite%20models%3A*&code_challenge=YOUR_BASE64URL_CHALLENGE&code_challenge_method=S256&state=YOUR_RANDOM_STATE
```

### Query parameters

<ParamField name="response_type" type="string" required>
  Must be `code`.
</ParamField>

<ParamField name="client_id" type="string" required>
  Your app's Client ID (`zrv_client_...`) from your Developer organization.
</ParamField>

<ParamField name="redirect_uri" type="string" required>
  Exact redirect URI registered in your app settings.
</ParamField>

<ParamField name="scope" type="string" required>
  Space-separated scopes. Must include `inference:write` and at least one `models:` scope such as `models:*` or `models:openai/*`.
</ParamField>

<ParamField name="code_challenge" type="string" required>
  Base64URL-encoded SHA-256 hash of your PKCE `code_verifier`.
</ParamField>

<ParamField name="code_challenge_method" type="string" required>
  Must be `S256`.
</ParamField>

<ParamField name="state" type="string" required>
  Random string used to prevent cross-site request forgery.
</ParamField>

## Exchange code for token

<ApiEndpoint method="POST" path="https://api.zorveus.com/oauth/token" />

Exchange a one-time authorization code and PKCE `code_verifier` for a user access token.

<CodeGroup titles={["TypeScript (@zorveus/sdk)", "Python (zorveus)", "cURL"]}>

```typescript
import { ZorveusOAuth } from "@zorveus/sdk";

const tokenData = await ZorveusOAuth.exchangeToken({
  clientId: "zrv_client_your_client_id",
  clientSecret: process.env.ZORVEUS_CLIENT_SECRET, // Omit for public clients
  code: authCodeFromRedirect,
  codeVerifier: originalVerifier,
  redirectUri: "https://myapp.com/callback",
});

console.log("Token:", tokenData.access_token);
```

```python
import os
from zorveus import ZorveusOAuth

token_data = ZorveusOAuth.exchange_token(
    client_id="zrv_client_your_client_id",
    client_secret=os.environ.get("ZORVEUS_CLIENT_SECRET"),  # Omit for public clients
    code=auth_code_from_redirect,
    code_verifier=original_verifier,
    redirect_uri="https://myapp.com/callback",
)

print("Token:", token_data.access_token)
```

```bash
curl -X POST https://api.zorveus.com/oauth/token \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "grant_type=authorization_code" \
  -d "client_id=zrv_client_your_client_id" \
  -d "client_secret=zrv_client_secret_your_secret" \
  -d "code=zorveus_code_abc123xyz" \
  -d "code_verifier=original_plain_code_verifier" \
  -d "redirect_uri=https://myapp.com/callback"
```

</CodeGroup>

### Request body (form URL-encoded)

<ParamField name="grant_type" type="string" required>
  Must be `authorization_code`.
</ParamField>

<ParamField name="client_id" type="string" required>
  Your app's Client ID.
</ParamField>

<ParamField name="code" type="string" required>
  One-time authorization code from the callback redirect query string.
</ParamField>

<ParamField name="code_verifier" type="string" required>
  Plain PKCE verifier used to generate `code_challenge`.
</ParamField>

<ParamField name="redirect_uri" type="string" required>
  Exact callback URL passed to `/oauth/authorize`.
</ParamField>

<ParamField name="client_secret" type="string">
  Required for confidential server backends. Omit for public browser and mobile clients.
</ParamField>

### Response

```json
{
  "access_token": "zrv_usr_9a8b7c6d5e4f3a2b1c0d",
  "token_type": "Bearer",
  "scope": "inference:write models:*",
  "expires_in": 2592000,
  "app_connection_id": "appcon_abc123",
  "api_base": "https://api.zorveus.com/v1"
}
```

<ResponseField name="access_token" type="string" required>
  User-scoped bearer token (`zrv_usr_...`) for `Authorization: Bearer ...` model requests.
</ResponseField>

<ResponseField name="token_type" type="string" required>
  Always `Bearer`.
</ResponseField>

<ResponseField name="scope" type="string" required>
  Permissions approved by the user.
</ResponseField>

<ResponseField name="expires_in" type="integer">
  Validity period in seconds, when an expiry is set.
</ResponseField>

<ResponseField name="app_connection_id" type="string" required>
  Unique ID for this authorized app connection.
</ResponseField>

<ResponseField name="api_base" type="string" required>
  Base gateway URL for model requests (`https://api.zorveus.com/v1`).
</ResponseField>

## Revoke token

<ApiEndpoint method="POST" path="https://api.zorveus.com/oauth/revoke" />

Revoke an issued user access token when the user disconnects or logs out.

<CodeGroup titles={["TypeScript (@zorveus/sdk)", "Python (zorveus)", "cURL"]}>

```typescript
import { ZorveusOAuth } from "@zorveus/sdk";

const result = await ZorveusOAuth.revokeToken({
  clientId: "zrv_client_your_client_id",
  clientSecret: process.env.ZORVEUS_CLIENT_SECRET, // Omit for public clients
  token: userAccessToken,
});

console.log("Revoked:", result.revoked);
```

```python
import os
from zorveus import ZorveusOAuth

result = ZorveusOAuth.revoke_token(
    client_id="zrv_client_your_client_id",
    client_secret=os.environ.get("ZORVEUS_CLIENT_SECRET"),  # Omit for public clients
    token=user_access_token,
)

print("Revoked:", result.revoked)
```

```bash
curl -X POST https://api.zorveus.com/oauth/revoke \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "client_id=zrv_client_your_client_id" \
  -d "client_secret=zrv_client_secret_your_secret" \
  -d "token=zrv_usr_token_to_revoke"
```

</CodeGroup>

### Request body (form URL-encoded)

<ParamField name="client_id" type="string" required>
  Your app's Client ID.
</ParamField>

<ParamField name="token" type="string" required>
  The user access token (`zrv_usr_...`) to revoke.
</ParamField>

<ParamField name="client_secret" type="string">
  Required for confidential server backends. Omit for public clients.
</ParamField>

### Response

```json
{
  "revoked": true
}
```

<ResponseField name="revoked" type="boolean" required>
  `true` if an active token was revoked. Repeating the request for an already revoked token returns `false`.
</ResponseField>
