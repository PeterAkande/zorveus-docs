title: OAuth endpoints
description: Authorize a user, exchange a code, and revoke an inference token.
---

OAuth uses Authorization Code with S256 PKCE. Register the app in the dashboard, then use these endpoints from your application

| Operation | Endpoint | Contract |
| --- | --- | --- |
| Start authorization | Browser navigation to `https://app.zorveus.com/oauth/authorize` | [Authorization request](/oauth/authorization-request) |
| Exchange a code | `POST https://api.zorveus.com/oauth/token` | [Form fields and response](/oauth/token-exchange) |
| Revoke a token | `POST https://api.zorveus.com/oauth/revoke` | [Revocation](/oauth/revocation) |

Token exchange and revocation accept `application/x-www-form-urlencoded`. Confidential clients include `client_secret` from their backend. Public clients omit it. Both client types use PKCE for authorization

The returned `access_token` is an inference credential. It does not grant dashboard access or product-user management permissions. There is no refresh-token grant. Use [reauthorization](/oauth/reauthorization) to replace a token or change consent

Start with the [OAuth app quickstart](/getting-started/oauth-app-quickstart). See [OAuth errors](/oauth/errors) for the JSON error contract
