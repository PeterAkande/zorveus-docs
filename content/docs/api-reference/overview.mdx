Use this reference for calls your application makes to Zorveus. Use the [dashboard](https://app.zorveus.com) for organizations, apps, connections, keys, caps, provider credentials, and webhooks. The service operations below support backend customer and allowance management

| Task | Endpoint or guide | Credential |
| --- | --- | --- |
| Generate text, embeddings, images, or audio | [Inference API](/inference/overview) under `https://api.zorveus.com/v1` | Inference key or scoped OAuth token |
| Read or update a customer and grant credits | [Product users](/api-reference/product-users) under `/product-users/by-external-id` | Server-only service key |
| Connect a user's funding account | [OAuth](/api-reference/oauth) | Client ID and PKCE, plus client secret for confidential clients |
| Inspect the selected key's spend | [Key usage](/api-reference/usage) at `/inference-keys/usage` | Inference key or scoped OAuth token |
| Find model IDs and capabilities | [Models](/api-reference/models) | Public catalog, or inference key for key-scoped discovery |

OpenAI-compatible clients use `https://api.zorveus.com/v1`. Product-user and OAuth requests use `https://api.zorveus.com` without `/v1`. Native Anthropic clients use `https://api.zorveus.com` because the SDK adds `/v1/messages`

See [Authentication](/platform/authentication), [errors](/platform/errors), and [idempotency](/platform/idempotency) for shared behavior

## OpenAPI schema

The backend schema is available at `https://api.zorveus.com/openapi.json`. It also includes dashboard operations that require browser sessions. Use the application endpoints documented here when building an integration. An endpoint's presence in the schema does not make it a service-key endpoint
