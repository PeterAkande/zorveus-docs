The Zorveus Product and Management API provides programmatic access to manage organizations, apps, inference keys, product users, and provider credentials.

---

## OpenAPI Specification

The complete, machine-readable OpenAPI 3.1 schema for all public endpoints is hosted at:

```text
https://api.zorveus.com/openapi.json
```

You can import this URL directly into **Postman**, **Insomnia**, **Swagger UI**, or code generation tools (e.g. `openapi-typescript`, `datamodel-code-generator`).

```bash
# Download the public OpenAPI spec
curl -O https://api.zorveus.com/openapi.json
```

## Production Servers

| Base URL | Purpose | Authentication |
| :--- | :--- | :--- |
| `https://api.zorveus.com` | Product Management API | `Authorization: Bearer zrv_svc_...` |
| `https://api.zorveus.com/v1` | OpenAI-compatible Inference Gateway | `Authorization: Bearer zrv_...` |

---

## Authentication Credentials

- **Service key (`zrv_svc_...`)**: Server-to-server management secret for supported routes on `https://api.zorveus.com`.
- **Inference Key (`zrv_...`)**: Fast edge token used in `Authorization: Bearer zrv_...` for AI completions on `https://api.zorveus.com/v1` or checking key usage on `/inference-keys/usage`.
- **Dashboard Session**: Browser session cookie with CSRF protection for web dashboard operations.
