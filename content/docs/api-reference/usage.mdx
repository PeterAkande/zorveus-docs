## Get API Key Usage Summary

Inspect live period spend, spending caps, and remaining balance using an API key directly.

<Callout type="tip" title="Public CORS Support">
  This endpoint has public CORS enabled and can be queried directly by browser clients and frontend extensions.
</Callout>
--

<ApiEndpoint method="GET" path="/inference-keys/usage" auth="api_key" />

### Headers

| Header | Value | Required | Description |
| :--- | :--- | :--- | :--- |
| `Authorization` | `Bearer <zrv_api_key>` | **Yes** | Your active Zorveus API key. |

<ApiRunner method="GET" path="/inference-keys/usage" authType="api_key" />
