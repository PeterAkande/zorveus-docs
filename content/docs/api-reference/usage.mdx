## Get Inference Key Usage Summary

Inspect live period spend, spending caps, and remaining balance using an inference key directly.

<Callout type="tip" title="Public CORS Support">
  This endpoint has public CORS enabled and can be queried directly by browser clients and frontend extensions.
</Callout>
--

<ApiEndpoint method="GET" path="/inference-keys/usage" auth="inference_key" />

### Headers

| Header | Value | Required | Description |
| :--- | :--- | :--- | :--- |
| `Authorization` | `Bearer <zrv_inference_key>` | **Yes** | Your active Zorveus inference key. |

<ApiRunner method="GET" path="/inference-keys/usage" authType="inference_key" />

#### Response (`200 OK`) — Capped Connection

```json
{
  "status": "active",
  "app_id": "app_mindspire_123",
  "app_connection_id": "appcon_01j...",
  "currency": "USD",
  "period": "monthly",
  "spend_cap": "50.000000000000",
  "spent_this_period": "12.500000000000",
  "remaining_balance": "37.500000000000",
  "reset_at": "2026-09-01T00:00:00Z"
}
```
