---
title: Bring your own key quickstart
description: Connect a provider account, make a request, and verify who paid.
---

Route a model request through a provider account your organization already owns. Your application still authenticates with a Zorveus inference key. The upstream provider secret stays in Zorveus

## Connect the provider

Select your Business organization in the [dashboard](https://app.zorveus.com), then open **Provider Credentials**. Choose the provider, enter the required secret and configuration, and save it. Check its validation status

Set a matching model policy such as `openai/*` and choose `auto_resolve` for automatic eligibility. For `manual_grant_only`, grant the credential to the app connection explicitly. See [Provider credentials](/startups/provider-credentials) for routing modes and rotation

The app connection must also allow the model. Adding a provider credential does not bypass model access rules

## Send a request

Use the inference key for that app connection and choose an available model from [model discovery](/inference/model-discovery). Follow the [Business quickstart](/getting-started/startup-quickstart) to send an attributed request. No upstream secret or provider override is needed in application code

For example, an `openai/*` credential is eligible for matching OpenAI requests. It is not eligible for an Anthropic request, even when the credential's policy is `*`

## Verify the funding path

Open **Usage** in the dashboard and inspect the completed request. Successful BYOK usage records `billing_mode: "byok_external"`. The upstream provider bills your provider account. `sell_cost` is the Zorveus wallet charge, which can include a configured platform fee

BYOK still consumes reference-priced customer allowance under the connection's policy. A product user with credits does not supply provider funds

## Choose fallback deliberately

Check `auto_fallback_to_wallet` before using the credential in production. Eligible provider failures can use a managed wallet-funded route when fallback is enabled, a route is available, and wallet funds can be reserved. That request is billed to your Zorveus wallet

A request that matches no eligible BYOK credential can use managed routing independently of fallback. Confirm the funding mode in usage. See [Automatic provider routing](/startups/automatic-routing) and [BYOK costs](/wallet-and-billing/byok-costs)
