Create a Zorveus API key, choose a model, and get a response using the standard OpenAI SDK or cURL.

<KeyInserter type="api" label="Your API Key" placeholder="zrv_your_api_key" />

<Steps>

<Step title="1. Create your API key">

Log in to the [Zorveus dashboard](https://app.zorveus.com) and create or select a **Business** organization.

1. Fund your organization wallet with a balance, or connect your upstream provider accounts under [Provider credentials](/startups/provider-credentials).
2. Create an App for your project or service.
3. Under Connection Settings, create an **Inference Key** (`zrv_...`). Copy the secret key to your environment store.

</Step>

<Step title="2. Pick a model">

Browse available models in the [Zorveus model catalog](https://www.zorveus.com/models), or query available models using the OpenAI SDK (`client.models.list()`) or cURL:

<CodeGroup titles={["cURL", "Python", "TypeScript"]}>

```bash
curl --fail-with-body https://api.zorveus.com/v1/models \
	-H "Authorization: Bearer zrv_your_api_key"
```

```python
from openai import OpenAI

client = OpenAI(
    api_key="zrv_your_api_key",
    base_url="https://api.zorveus.com/v1",
)

models = client.models.list()
for model in models.data:
    print(model.id)
```

```typescript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "zrv_your_api_key",
  baseURL: "https://api.zorveus.com/v1",
});

const models = await client.models.list();
for (const model of models.data) {
  console.log(model.id);
}
```

</CodeGroup>

Pick an active model ID from the response, such as `openai/gpt-4.1-mini` or `anthropic/claude-3-5-sonnet`.

</Step>

<Step title="3. Send your first completion">

Zorveus provides an OpenAI-compatible gateway at `https://api.zorveus.com/v1`. You can use the standard OpenAI SDK in Python or TypeScript, or plain HTTP requests. Pass your Zorveus API key as the bearer token.

<CodeGroup titles={["Python (OpenAI SDK)", "TypeScript (OpenAI SDK)", "cURL"]}>

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key="zrv_your_api_key",
    base_url="https://api.zorveus.com/v1",
)

response = client.chat.completions.create(
    model="openai/gpt-4.1-mini",
    messages=[{"role": "user", "content": "Write a one-sentence welcome message."}],
)

print(response.choices[0].message.content)
```

```typescript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "zrv_your_api_key",
  baseURL: "https://api.zorveus.com/v1",
});

const response = await client.chat.completions.create({
  model: "openai/gpt-4.1-mini",
  messages: [{ role: "user", content: "Write a one-sentence welcome message." }],
});

console.log(response.choices[0].message.content);
```

```bash
curl --fail-with-body https://api.zorveus.com/v1/chat/completions \
	-H "Authorization: Bearer zrv_your_api_key" \
	-H "Content-Type: application/json" \
	-d '{
		"model": "openai/gpt-4.1-mini",
		"messages": [{"role": "user", "content": "Write a one-sentence welcome message."}]
	}'
```

</CodeGroup>
