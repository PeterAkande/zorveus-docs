If you pay for your users' AI inference, Zorveus gives you complete control over your costs.

No user can ever spend more than their allocated limit. Set spending caps by plan tier, issue promotional credits, track usage, and make your AI expenses 100% predictable—without building custom billing or gateway systems.

---

## 1. Create a Startup Org, API Key, and Spend Limit

Before making inference requests in code, set up your organization and configure an API key with a spend limit in the [Zorveus Dashboard](https://app.zorveus.com):

<Steps>
  <Step title="Create a Startup Organization">
    Log in to [app.zorveus.com](https://app.zorveus.com) and create or select your company's **Startup** organization.
  </Step>
  <Step title="Create an App and API Key">
    Navigate to **Apps**, create a new application (e.g. `My AI SaaS`), and click **Create Key** under **Inference Keys**. Copy your generated key (`zrv_live_...`).
  </Step>
  <Step title="Attach a Spending Limit">
    Select your API key in the dashboard, open **Spending Cap / Limit**, and set a monthly allowance for every user (e.g. `$10.00/month`). When a user's usage reaches this limit, Zorveus automatically blocks over-cap requests.
  </Step>
</Steps>

<Callout type="note" title="One-Time Secret Display">
  Inference keys (`zrv_live_...`) appear in plaintext only upon creation. Zorveus stores cryptographic hashes and cannot retrieve the raw secret later.
</Callout>

## 2. Make an Inference Request in Code

Send requests through Zorveus passing product user details (`external_user_id`, `display_name`, `email`, `user_metadata`) using the official `@zorveus/sdk` TypeScript client, the `zorveus` Python library, the Vercel AI SDK provider, or any standard OpenAI SDK pointing to `https://api.zorveus.com/v1`:

<KeyInserter type="inference" label="Test Key Inserter" placeholder="zrv_your_inference_key" />

<CodeGroup titles={["TypeScript (@zorveus/sdk)", "Python (zorveus)", "Python (ZorveusOpenAI)", "Vercel AI SDK (@zorveus/sdk/vercel)", "cURL", "Python (OpenAI SDK)", "TypeScript (OpenAI SDK)"]}>

```typescript
import { Zorveus } from "@zorveus/sdk";

// Initialize Zorveus client with API key and product user attribution
const client = new Zorveus({
  apiKey: "zrv_your_inference_key",
  externalUserId: "usr_sara_101", // Your internal user ID
  displayName: "Sara Connor",     // Optional user name for dashboard
  email: "sara@example.com",       // Optional user email
  userMetadata: { plan: "pro" },   // Optional custom metadata
});

async function main() {
  // Send completion request — usage is attributed and capped per user
  const completion = await client.chat.completions.create({
    model: "openai/gpt-4.1-mini",
    messages: [
      { role: "system", content: "You are a helpful coding assistant." },
      { role: "user", content: "Write a Python function to check for prime numbers." },
    ],
    temperature: 0.7,
  });

  console.log(completion.choices[0].message.content);
}

main();
```

## 3. Tiered Plan Control (Different API Keys per Plan)

Startups structure pricing around tiered subscription plans (such as Free, Starter, Pro, and Enterprise).

Because every Zorveus API key carries its own spending limits and model access rules, managing multi-tier pricing plans requires no custom gateway logic:

1. **Free Tier Key**: Attach a low monthly spend limit (e.g. `$1.00/month`) restricted to budget models like `openai/gpt-4.1-mini`.
2. **Pro Tier Key**: Attach a higher monthly allowance (e.g. `$20.00/month`) with access to flagship models like `openai/gpt-4o` and `anthropic/claude-3.5-sonnet`.
3. **Enterprise Tier Key**: Attach custom high-volume caps or unlimited spending with dedicated provider routing.

When a customer upgrades or downgrades their plan in your application, assign them the corresponding tier's API key or update the key's bound spending limit in the dashboard or via the [Zorveus Service API](/startups/service-keys).

### Example: Tiered Plan Selection in Backend Code

<CodeGroup titles={["TypeScript (@zorveus/sdk)", "Python (zorveus)"]}>

```typescript
import { Zorveus } from "@zorveus/sdk";

// Map your app subscription plans to tier-specific Zorveus keys
const PLAN_KEYS: Record<string, string> = {
  free: process.env.ZORVEUS_FREE_TIER_KEY!,    // $1.00/mo cap, budget models
  pro: process.env.ZORVEUS_PRO_TIER_KEY!,      // $20.00/mo cap, flagship models
  enterprise: process.env.ZORVEUS_ENTERPRISE_KEY!,
};

export async function handleUserInference(user: { id: string; name: string; plan: "free" | "pro" }) {
  // Select key bound to user's plan tier
  const apiKey = PLAN_KEYS[user.plan] || PLAN_KEYS.free;

  const client = new Zorveus({
    apiKey,
    externalUserId: user.id,
    displayName: user.name,
    userMetadata: { plan: user.plan },
  });

  return await client.chat.completions.create({
    model: user.plan === "pro" ? "openai/gpt-4o" : "openai/gpt-4.1-mini",
    messages: [{ role: "user", content: "Analyze market trends." }],
  });
}
```

```python
import os
from zorveus import Zorveus

# Map your app subscription plans to tier-specific Zorveus keys
PLAN_KEYS = {
    "free": os.environ["ZORVEUS_FREE_TIER_KEY"],      # $1.00/mo cap, budget models
    "pro": os.environ["ZORVEUS_PRO_TIER_KEY"],        # $20.00/mo cap, flagship models
    "enterprise": os.environ["ZORVEUS_ENTERPRISE_KEY"],
}

def handle_user_inference(user_id: str, display_name: str, plan: str):
    # Select key bound to user's plan tier
    api_key = PLAN_KEYS.get(plan, PLAN_KEYS["free"])

    client = Zorveus(
        api_key=api_key,
        external_user_id=user_id,
        display_name=display_name,
        user_metadata={"plan": plan}
    )

    model = "openai/gpt-4o" if plan == "pro" else "openai/gpt-4.1-mini"

    return client.chat.completions.create(
        model=model,
        messages=[{"role": "user", "content": "Analyze market trends."}]
    )
```
