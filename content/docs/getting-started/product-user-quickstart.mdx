In Zorveus, **Product Users** represent your application's end users. Instead of building complex usage-tracking databases, you pass your customer's ID directly in the inference request metadata.

<KeyInserter type="inference" label="Inference Key Tester" placeholder="zrv_your_inference_key" />

---

## Streamlined 2-Step Workflow

Connecting and tracking end-user consumption requires only two steps:

1. **Automatic Inline Provisioning During Inference**: Pass `external_user_id` inside your inference calls. Zorveus creates or updates the user profile automatically on their first request.
2. **Querying User Details and Credit Balance**: Use `ZorveusServiceClient` with an Organization Service Key (`zrv_sk_...`) to inspect profile details, credit balances, or issue promotional top-ups.

---

## Step 1: Automatic Inline Provisioning During Inference

When Zorveus processes an inference request containing an `external_user_id` it has not seen before, it **automatically creates the product user inline** in your startup workspace.

Subsequent requests with the same `external_user_id` update the product user's profile metadata (e.g. name, email, plan) and aggregate usage seamlessly.

<CodeGroup titles={["Python (ZorveusOpenAI)", "TypeScript (@zorveus/sdk)", "Python (zorveus)", "TypeScript (ZorveusOpenAI)", "TypeScript (Vercel AI SDK)", "Python (OpenAI SDK)", "cURL"]}>

```python
# pip install zorveus[openai]
from zorveus.openai import ZorveusOpenAI

# User is created automatically on their first inference call
client = ZorveusOpenAI(
    api_key="zrv_live_123...",
    external_user_id="usr_sara_101",
    display_name="Sara Connor",
    email="sara@example.com",
    user_metadata={"plan": "pro"}
)

response = client.chat.completions.create(
    model="openai/gpt-4.1-mini",
    messages=[{"role": "user", "content": "Hello!"}]
)

print(response.choices[0].message.content)
```

```typescript
import { Zorveus } from "@zorveus/sdk";

const client = new Zorveus({
  apiKey: "zrv_live_123...",
});

async function main() {
  const completion = await client.chat.completions.create({
    model: "openai/gpt-4.1-mini",
    messages: [
      { role: "user", content: "Summarize the latest trends in renewable energy." },
    ],
    // Pass typed Zorveus product-user metadata
    zorveusMetadata: {
      externalUserId: "usr_sara_101",
      displayName: "Sara Connor",
      userEmail: "sara@example.com",
      metadata: {
        plan: "pro",
      },
    },
  });

  console.log(completion.choices[0].message.content);
}

main();
```

## Step 2: Query User Details and Credit Balance

When you need to view user profile details, active credit grants, or remaining balance, use `ZorveusServiceClient` with an Organization Service Key (`zrv_sk_...`):

<CodeGroup titles={["Python (zorveus)", "TypeScript (@zorveus/sdk)", "cURL"]}>

```python
from zorveus import ZorveusServiceClient

service = ZorveusServiceClient(api_key="zrv_sk_live_123...")

user_info = service.product_users.get_by_external_id(
    app_id="app_123",
    external_user_id="usr_sara_101"
)

print("Display Name:", user_info.product_user.display_name)
print("Available Credits:", user_info.credit_summary.available_credits)
```

```typescript
import { ZorveusServiceClient } from "@zorveus/sdk";

const service = new ZorveusServiceClient({
  apiKey: "zrv_sk_live_123...",
});

const userInfo = await service.productUsers.getByExternalId({
  appId: "app_123",
  externalUserId: "usr_sara_101",
});

console.log("Display Name:", userInfo.product_user.display_name);
console.log("Available Credits:", userInfo.credit_summary.available_credits);
```

```bash
curl -X GET "https://api.zorveus.com/api/v1/product-users/by-external-id?app_id=app_123&external_user_id=usr_sara_101" \
  -H "Authorization: Bearer zrv_sk_live_123..."
```

</CodeGroup>

  User creation is automatic! You only need to call `grant_credit_by_external_id` (or `grantCreditByExternalId` in TS) when explicitly adding top-up credits or promotional allowances to a user's balance.
</Callout>

## Identifier Resolution Precedence

When attributing requests to product users, Zorveus applies the following hierarchy:

1. **`external_user_id` (Recommended)**: Your own database primary key (e.g. `usr_98124`, `auth0|123456`). Zorveus indexes and resolves this immediately.
2. **`product_user_id`**: An internal Zorveus UUID if you previously fetched or created the product user via the Management API.
3. **OpenAI `user` field**: If `metadata.external_user_id` is omitted, Zorveus falls back to the standard OpenAI top-level `user` string as the `external_user_id`.

## Observing Product Users in Dashboard

After making the request:
1. Go to [app.zorveus.com](https://app.zorveus.com) -> **Product Users**.
2. Search for `usr_sara_101` or `Sara Connor`.
3. View the customer's:
   - Lifetime token consumption and requests
   - Remaining credit balance (if credit grants are applied)
   - Spending caps and active rate limits
   - Full timeline of AI requests
