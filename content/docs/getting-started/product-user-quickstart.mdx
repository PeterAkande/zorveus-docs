---
title: Add customer usage limits
description: Give each customer an AI spending limit and check what they have left.
---

With Zorveus, you control how much AI each customer of your product can use. For example, a user on a \$5 subscription plan can get a \$2 monthly (or daily) AI limit. Every customer receives an isolated allowance, so one user's heavy spending never drains another customer's balance.

If you haven't made a model request yet, follow the [API quickstart](/getting-started/startup-quickstart) to set up your app and API key.

## 1. Set the plan's allowance

In the [dashboard](https://app.zorveus.com), open your app's connection settings.

- Set **Cap amount** to `$2` and **Period** to `monthly`. <InfoTooltip label="Cap amount and period">Each customer gets their own $2 allowance every month.</InfoTooltip>
- Set **Credit mode** to `enforce`. <InfoTooltip label="Credit mode">Zorveus checks the customer's remaining allowance before accepting a request.</InfoTooltip>
- Set **Overrun policy** to `limit_output`. <InfoTooltip label="Overrun policy">Zorveus lowers the model's maximum response length to fit the allowance.</InfoTooltip>

Your backend chooses the API key for the customer's subscription plan. The examples below call it `ZORVEUS_API_KEY`.

## 2. Show their starting balance

Create a [service key](/startups/service-keys) with `product_users:read` permission so your backend can read customer balances. Save it as `ZORVEUS_SERVICE_KEY` and your app ID as `ZORVEUS_APP_ID`. Keep the service key and plan key on your server.

Pass the customer's plan key as `inferenceKey` so Zorveus knows which allowance to use. With `upsertIfMissing: true`, this read also creates their customer record. You can show a balance before their first AI request.

Replace `customer_42` below with the ID from your backend's signed-in user session.

<CodeGroup titles={["Python (zorveus)", "TypeScript (@zorveus/sdk)", "cURL"]}>

```python
import os
from zorveus import ZorveusServiceClient

service = ZorveusServiceClient(service_key=os.environ["ZORVEUS_SERVICE_KEY"])

user = service.product_users.get_by_external_id(
	app_id=os.environ["ZORVEUS_APP_ID"],
	external_user_id="customer_42",
	inference_key=os.environ["ZORVEUS_API_KEY"],
	upsert_if_missing=True,
)

print(user.allowance.available_allowance if user.allowance else None)
```

```typescript
import { ZorveusServiceClient } from "@zorveus/sdk";

const service = new ZorveusServiceClient({
	apiKey: process.env.ZORVEUS_SERVICE_KEY!,
});

const user = await service.productUsers.getByExternalId({
	appId: process.env.ZORVEUS_APP_ID!,
	externalUserId: "customer_42",
	inferenceKey: process.env.ZORVEUS_API_KEY!,
	upsertIfMissing: true,
});

console.log(user.allowance?.available_allowance ?? null);
```

```bash
curl --fail-with-body --get https://api.zorveus.com/product-users/by-external-id \
	-H "Authorization: Bearer $ZORVEUS_SERVICE_KEY" \
	-H "X-Zorveus-Inference-Key: $ZORVEUS_API_KEY" \
	-H "X-Zorveus-Upsert-Product-User: true" \
	--data-urlencode "app_id=$ZORVEUS_APP_ID" \
	--data-urlencode "external_user_id=customer_42"
```

</CodeGroup>

Use `allowance.available_allowance` for the amount left in USD. A new customer on this plan starts with \$2. Keep the value as a decimal string. If it is `null`, show "Balance unavailable".

Use `allowance.period_end` to show when the allowance resets.

## 3. Send AI requests for that customer

Use the customer's selected plan key and the same customer ID in each model request.

<CodeGroup titles={["Python", "TypeScript (@zorveus/sdk)", "cURL"]}>

```python
import os
from openai import OpenAI

with OpenAI(
	api_key=os.environ["ZORVEUS_API_KEY"],
	base_url="https://api.zorveus.com/v1",
) as client:
	response = client.chat.completions.create(
		model=os.environ["ZORVEUS_MODEL"],
		messages=[{"role": "user", "content": "Hello"}],
		extra_headers={"X-Zorveus-External-User-ID": "customer_42"},
	)
	print(response.choices[0].message.content)
```

```typescript
import { Zorveus } from "@zorveus/sdk";

const client = new Zorveus({ apiKey: process.env.ZORVEUS_API_KEY! });
const response = await client.chat.completions.create({
	model: process.env.ZORVEUS_MODEL!,
	messages: [{ role: "user", content: "Hello" }],
	zorveusMetadata: { externalUserId: "customer_42" },
});

console.log(response.choices[0].message.content);
```

```bash
curl --fail-with-body https://api.zorveus.com/v1/chat/completions \
	-H "Authorization: Bearer $ZORVEUS_API_KEY" \
	-H "Content-Type: application/json" \
	-H "X-Zorveus-External-User-ID: customer_42" \
	-d '{
		"model": "openai/gpt-4.1-mini",
		"messages": [{"role": "user", "content": "Hello"}]
	}'
```

</CodeGroup>

Zorveus tracks the customer's spending. Read their allowance again after the request to refresh the balance shown in your UI.

## When the allowance runs out

If the allowance cannot cover a request, Zorveus returns HTTP `403` with `zorveus_product_user_allowance_insufficient`. The customer can retry after the allowance resets.

When you're ready to connect limits to subscriptions and customer payments, follow [Build customer billing](/getting-started/integrate-your-product).
