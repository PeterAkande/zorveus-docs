Let your coding agent add Zorveus to your app. Choose what you need, copy the prompt, and paste it into your agent.

## 1. Copy a prompt

<IntegrationPromptPicker />

## 2. Give your agent a task

In your coding agent, describe what you want to build. For example:

> Add a chat feature to this app using Zorveus. Follow the integration instructions below and use the project's existing framework.

Paste the copied prompt underneath your task. Tell the agent which model to use, or ask it to help you choose from the [model catalog](https://www.zorveus.com/models).

Store API keys in environment variables. Keep secret values out of chat.

Ask the agent to run a test request and show you the response to check that the integration works.

## Optional: let your agent configure Zorveus

Your agent can also inspect your Zorveus apps and prepare configuration changes for you to review using the [CLI](/cli/quickstart) and the [MCP server](/cli/mcp). Follow [Connect a coding agent with MCP](/cli/mcp) to set this up.

You can use the integration prompts without MCP setup.

Your agent can use the [documentation index](https://docs.zorveus.com/llms.txt) to find guides and their Markdown sources.
