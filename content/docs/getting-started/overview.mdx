Zorveus provides three core integration models depending on who funds the AI usage and how credentials are managed.

---

## Choose your integration mode

| Business Goal | Integration Mode | Funding Source | Key Credential |
| :--- | :--- | :--- | :--- |
| **Startup funds its own product** | [Startup Quickstart](/getting-started/startup-quickstart) | Startup Organization Wallet | API Key (`zrv_...`) |
| **Startup uses existing provider keys** | [BYOK Quickstart](/getting-started/byok-quickstart) | Upstream Provider (Direct) | API Key + Stored Provider Secret |
| **End-user funds third-party app** | [OAuth App Quickstart](/getting-started/oauth-app-quickstart) | User's Personal/Company Wallet | Scoped OAuth Token (`zrv_...`) |

<Callout type="info" title="Need an API key? Choose a Startup Organization">
  If you want an API key (`zrv_...`) to call models from your code, server backend, or scripts, select or create a **Startup Organization** in the dashboard. Even if you are a solo developer building an independent project, Startup is the workspace that funds AI and mints API keys. A **Developer Organization** only registers third-party OAuth applications where end-users bring their own wallets.
</Callout>

## Credential terminology

Understanding credential types ensures you use the correct secret in each context:

- **API Key (`zrv_...`)**: Secret token used in `Authorization: Bearer zrv_...` against the model gateway (`https://api.zorveus.com/v1` or native wire endpoints). Used to execute model inference and inspect connection spend. Shown only once upon creation.
- **Service Key (`zrv_svc_...`)**: High-privilege management credential used server-to-server against the Product Management API (`https://api.zorveus.com`). Reserved for backend administration; never expose this key in browser code and do not pass it to inference endpoints.
- **Client ID & Client Secret (`zrv_client_...` / `zrv_client_secret_...`)**: Credentials for registered OAuth applications to authenticate during PKCE token exchanges.
- **Provider Credential**: Encrypted upstream API keys (e.g. OpenAI, Anthropic, Gemini) stored in Zorveus for Bring Your Own Key (BYOK) routing.

<Callout type="warning" title="Security Boundary">
  Never use a **Service Key** (`zrv_svc_...`) for model inference requests or inside frontend client bundles. Service keys are strictly for backend management (managing product users, credit grants, provider credentials, and connections). Model inference requires an **API Key** (`zrv_...`).
</Callout>

## Production endpoints

Always use production endpoints in deployed applications:

```text
Inference Base URL:  https://api.zorveus.com/v1
Management Base URL: https://api.zorveus.com
OAuth Authorize URL: https://app.zorveus.com/oauth/authorize
```
